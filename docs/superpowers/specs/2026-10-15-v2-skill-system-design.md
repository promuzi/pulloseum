# v2 기술 체계 · 기술 얻는 방식 · 효과 짝 · 탐사 동기 — 논의안 (2026-10-15)

> 상태: **논의 중(구현 전)**, 효과 짝표만 확정·적용(63810e7 — 시제품 식물 기술표가 짝표를 따름). 지금 전투는 기본기 셋 + 식물마다 기술 둘(`v2/src/battle/model.js` SKILLS).
> 용어(사용자 "타입은 '종'으로 바꾸자"): **종** = 꽃 · 덩굴 · 선인장 · 버섯 / **속성** = 불 · 물 · 풀 · 대지 · 바람 · 번개 · 빙결 / **식물** = 페탈로즈 같은 하나하나 / **개체** = 같은 식물 중 하나 / **생장** = 어린 · 자라는 · 다 자란(그림 세 단계).

## 1. 사용자 지시
- (1차) 기술은 **공통**과 **개성**으로. 공통 = 생장·속성·종에 따라 겹쳐 가짐, 개성 = 한 식물만, 생장에 따라 1 / 1~2 / 3개. 변종·경계 식물은 이웃 속성·종 기술도(포켓몬처럼). 공통과 개성 사이 **중간 층**. 지금 얻는 방식(경험치로 자동 열림 + 카드)은 "직관적이지 않고 너무 재미없음". 효과는 속성과 짝(화상 = 불, 가속 = 바람) — 디버프는 전용, 버프는 더 넓게.
- (2차) 중간(가지) 기술은 가까운 식물이 기본이지만 **먼 행성의 특이한 식물은 컨셉상 예외로 가질 수 있음**. 공통도 **급을 나눠**, 상위 기술은 다 배우는 게 아니라 몇 개만(정해지거나 무작위 — 고민). **효과 짝표 좋음**, **버프는 공통 기술로 넣기**, **버섯 디버프는 '포자'로**, **덩굴은 덩굴 묶기만** — 기생 씨앗 · 뿌리 묶기는 속성·종·생장에 묶이지 않는 **변이·특수 기술**로(덩굴 몰빵 방지). 얻는 방식은 A가 매력적이나 단계를 놓치면 손해인지, 자유 선택 대신 **접목(포켓몬 기술머신처럼) + C** — 이 부분은 따로 깊게.
- (2차) 걱정: 식물을 얻으면 다시 탐사할 이유가 줄어듦. 등급 격차가 크면 최종 개체 전엔 투자를 꺼리고, 배울 기술이 무작위면 꽝일 때 투자가 손해. 투자 환급은 돈 가치를 떨어뜨림. 암시장 환급·유저 거래도 생각했지만 애매.

## 2. 기술 층(추천 이름: 뿌리 · 가지 · 꽃)
| 층 | 누가 갖나 | 예 |
|---|---|---|
| 공통(뿌리 기술) | 같은 속성 또는 같은 종이면 누구나 — 단 **상급은 개체마다 몇 개만**(§2-1) | 불 하급: 불씨 · 중급: 화염구 · 상급(여럿 중 몇): 불기둥 · 화염 폭풍 · 용암 분출 |
| 중간(가지 기술) | 가까운 식물 무리끼리 + **먼 행성 특이 식물은 컨셉상 예외** | 사막 가지(선인장 + 불·대지) · 물가 가지(물 + 덩굴) |
| 개성(꽃 기술) | 그 식물만, 어린 1 · 자라는 1~2 · 다 자란 3 | 엠버캑터: 불가시 난사(화상 + 반사) |
| 변이·특수 | 속성·종·생장과 무관 — 변이나 특별한 길로 | 기생 씨앗 · 뿌리 묶기 · 그늘 · 부식 |
- 곁가지: 변종(번개 + 땅 느낌)·경계 식물(버섯 ↔ 덩굴)은 이웃 속성·종의 공통 기술 일부도.

### 2-1. 공통 상급 기술 — 개체마다 몇 개
- 하급·중급 = 그 속성·종이면 다 배움. 상급(불이면 셋~넷) = **개체마다 둘쯤만**.
- 어느 둘인지는 **식물을 얻는 순간 정해지고 바로 보임**(무작위여도 투자하기 전에 앎) → 키우다 꽝이 나는 일이 없음.
- 원하는 상급이 없으면 §5의 접붙이기로 다른 개체에게서 옮겨 받음 → 그 기술을 가진 개체를 찾으러 다시 탐사할 이유가 됨.

## 3. 효과 짝(확정 — 사용자 "효과 짝표 좋아")
| 속성 | 디버프(전용) | 버프(대표, 다른 식물도) | 공통 버프 기술(예) |
|---|---|---|---|
| 불 | 화상 | 분노(공격 ↑) | 불타오르기 |
| 물 | 젖음 | 정화(나쁜 효과 지움) | 맑은 물 |
| 풀 | 독 | 재생(턴마다 회복) | 광합성 |
| 대지 | 기절 | 철벽(받는 피해 ↓) | 단단해지기 |
| 바람 | 꽃가루(적중 ↓) | 가속(기동성 ↑) | 순풍 |
| 번개 | 감전 | 집중(치명 ↑) | 정전기 충전 |
| 빙결 | 빙결 | 보호막 | 얼음 껍질 |

| 종 | 디버프(전용) | 버프 |
|---|---|---|
| 꽃 | 약화(향기에 힘이 빠짐) | — |
| 덩굴 | 덩굴(기술 하나 묶기)만 | — |
| 선인장 | 도발(자세 못 씀) | 반사(가시) — 공통 버프 기술 '가시 세우기' |
| 버섯 | 포자(자라서 피어나면 피해 + 숨 막힘) | — |
- 기술 = 제 이름 + 효과(+ 덤): '화염구' = 화상, 개성 '불가시 난사' = 화상 + 반사.
- '광합성'은 옛 판의 회복 기술 이름 → 풀 공통 버프 기술 이름으로 다시 씀(효과 = 재생).

## 4. 기술 얻는 방식(깊게는 따로 — 사용자 "이따가 얘만 파보자")
- 지금 방향: A(자라서 피어나기) + 접목(기술 씨앗 = 포켓몬 기술머신처럼, 접붙이기) + C(가꾸는 대로) 조금.
- 놓친 단계 기술은 손해? → 놓친 개성 기술은 언제든 '되새김'(포켓몬 기술 떠올리기)으로 다시 배움 → 손해 없음.
- 열린 것: 자유롭게 바꾸고 고르는 정도(언제든 바꿈 vs 화분·장소에서만 바꿈), 기술 씨앗 얻는 곳, 접붙이기 비용.

## 5. 탐사 동기 · 투자 위험(추천)
원칙 = **무작위는 줍는 순간에만, 키운 뒤엔 안전** + **같은 식물을 또 주울 이유**.
1. **줍는 순간 다 보임:** 등급 · 곁속성 · 상급 공통 기술(이 개체의 몇 개)을 얻을 때 공개 → 투자 전에 판단(포켓몬 능력 판정, 팰월드 패시브처럼).
2. **등급 차이는 작게**(능력치 ±5% 안팎) + **같은 식물로 올릴 수 있음** — 같은 식물을 거름으로 먹여 등급 ↑(파이어 엠블렘 히어로즈 합성, 팰월드 응축기처럼) → 낮은 등급에 투자해도 나중에 올라감.
3. **접붙이기:** 같은 식물(또는 같은 가지)의 다른 개체가 가진 기술을 옮겨 받음(포켓몬 알 기술·기술머신처럼) → 원하는 기술이 없어도 막다른 길이 아님.
4. **옮겨심기(돈 환급 대신):** 키운 만큼(생장 · 강화)을 같은 식물의 더 좋은 개체로 옮김, 조금 줄여서(예 80%) → 돈 가치는 그대로, 투자는 안 날아감.
5. **남는 개체 쓰임:** 거름(등급 ↑) · 접붙이기 재료 · 분해(재료로 조금) → 어떤 개체를 주워도 꽝이 아님.
6. **탐사 이유(식물 말고도):** 새 식물 · 지역 변종(같은 식물도 행성마다 곁속성·가지 기술이 다름) · 먼 행성 특이 식물 · 원하는 상급 기술을 가진 개체 · 거름감 · 기술 씨앗 · 변이 촉매 · 꾸미기 재료 · 도감 보상.
- **암시장 '무조건 환급':** 위험이 0이면 고르는 무게도 사라지고 돈이 불어남 → 하더라도 '분해기'(돈 대신 비료·씨앗 같은 재료로 30~50%).
- **유저 장터:** 같이 하는 재미는 있지만 시세 관리 · 작업장(봇) · 현금 거래 · 대전 공정성(돈으로 센 식물 사기) 문제가 커서 첫 출시엔 비추천. 하려면 포켓몬처럼 1:1 교환부터(친구끼리, 키운 만큼은 초기화 등 제한).
