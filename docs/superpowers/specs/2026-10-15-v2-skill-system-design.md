## 1. 사용자 지시(2026-10-15)
- 기술은 **공통 기술**과 **개성 기술**로 나눈다.
  - 공통 = 생장 · 속성 · 종에 따라 여러 식물이 겹쳐 갖는 기술.
  - 개성 = 한 식물만 갖는 기술, 생장에 따라 **1 / 1~2 / 3개**.
- 변종처럼 번개지만 땅 느낌이 나는 식물은 종종 땅 기술을 가짐. 종이 버섯이지만 덩굴과 경계가 애매한 식물은 덩굴 공통 기술이나 그런 디버프 기술도 가질 수 있음(포켓몬처럼).
- 공통과 개성의 **중간**: 모두가 공유하지는 않지만 한 식물이 독점하지도 않는 기술.
- 기술 얻는 방식은 지금 방식(생장 경험치로 자동으로 열림 + 카드 장착)에서 벗어나야 함 — "직관적이지 않고 너무 재미없음".
- 기술은 제 이름이 있고(예: 화염구), 효과는 효과 이름으로 붙음(화상) + 덤 효과. **버프·디버프를 속성과 짝지음**(화상 = 불, 가속 = 바람). 디버프는 그 속성 전용, 버프는 더 여러 식물·기술에 들어갈 수 있음.

## 2. 기술 세 층(추천 이름: 뿌리 · 가지 · 꽃)
| 층 | 누가 갖나 | 예 | 정하는 것 |
|---|---|---|---|
| 공통(뿌리 기술) | 같은 속성 또는 같은 종이면 누구나, 생장으로 열림 | 불: 불씨(어린) → 화염구(자라는) → 불기둥(다 자란) · 덩굴 종: 휘감기 | 속성 7 × 생장 3 + 종 4 × 생장 3 |
| 중간(가지 기술) | 같은 '가지'(가까운 식물 무리)끼리 | 사막 가지(선인장 + 불·대지): 모래 바람 · 물가 가지(물 + 덩굴): 물이끼 | 가지 몇 개와 소속 |
| 개성(꽃 기술) | 그 식물만 | 엠버캑터: 불가시 난사(화상 + 반사) | 식물마다 어린 1 · 자라는 1~2 · 다 자란 3(가진 개수) |
- **곁가지:** 변종(번개 + 땅 느낌)·경계 식물(버섯 ↔ 덩굴)은 이웃 속성·종의 공통 기술 일부를 배울 수 있음. 식물 정보에 '곁속성'·'곁종' 한 칸.
- 전투에 들고 가는 칸은 지금처럼 6칸(기본기 셋 포함). 배운 것 중 고름.

## 3. 기술 얻는 방식 — 세 안
| 안 | 얻는 법 | 재미 | 다른 게임 |
|---|---|---|---|
| A. 피어나기 · 씨앗 · 접붙이기(추천) | 개성 = 생장해서 다음 단계가 되는 순간 꽃봉오리가 피며 새 기술(칸이 차 있으면 바꿀지 고름) · 공통 = 탐사·상점·대회 보상으로 얻는 **기술 씨앗**을 화분에 심으면 배움(속성·종·생장이 맞아야) · 가지 = 같은 가지의 식물끼리 **접붙이기**로 옮김 | 자라는 순간이 이벤트가 되고, 탐사·양육과 바로 이어짐 | 포켓몬(레벨업 때 "배우고 싶어 한다", 기술머신, 알 기술) |
| B. 겪으며 배우기 | 맞아 보거나 써 본 기술을 배움(같은 속성·종이면 몇 번 맞으면 익힘) | 싸움이 곧 배움, 상대마다 얻는 게 다름 | 파이널 판타지 청마도사, 커비 |
| C. 가꾸는 대로 | 물·비료·햇빛 등 돌본 방식에 따라 다른 기술 봉오리가 맺힘 | 같은 식물도 키운 사람마다 달라짐 | 디지몬 월드(돌봄 → 진화), 다마고치 |
- 추천 = **A 바탕 + C를 조금**(비료 종류가 어떤 공통 기술 씨앗이 잘 맞는지에 영향). 화면에서는 배운 기술이 식물 위 **봉오리**로 보이고 누르면 이름·효과.
- 지금 방식(경험치 → 자물쇠 풀림)은 "언제 무엇이 열리는지"만 있고 고르는 순간·얻는 장면이 없어 밋밋함.

## 4. 효과와 속성·종 짝(추천)
디버프 = 그 속성·종 전용(곁가지 식물은 예외), 버프 = 대표 속성이 있지만 다른 식물도 가질 수 있음.

| 불 | 화상 | 분노 |
| 물 | 젖음 | 정화 |
| 풀 | 독(독초·가시) | 재생(광합성) |
| 대지 | 기절 | 철벽 |
| 바람 | 꽃가루(바람이 날림) | 가속 |
| 번개 | 감전 | 집중 |
| 빙결 | 빙결 | 보호막 |

| 종 | 디버프(전용) | 버프(대표) |
|---|---|---|
| 꽃 | 약화(향기에 힘이 빠짐) | — |
| 덩굴 | 덩굴 · 뿌리 묶기 · 기생 씨앗(새삼처럼 붙어 사는 덩굴) | — |
| 선인장 | 도발 | 반사(가시) |
| 버섯 | 그늘 · 부식 | — |
- 기술 = 제 이름 + 효과 하나(+ 덤): 공통 '화염구' = 화상 · 개성 '불가시 난사' = 화상 + 반사(덤) 같은 꼴.
