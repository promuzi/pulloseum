# 기술 · 상태 이상 구분 — 분석 · 조사 · 시안 (2026-10-29)

> 사용자: '그리고 스킬 쓰면 간단하게 식물 위로 글자만 삑 올라오는데 이게 스킬인지 상태이상인지 구분이 안 돼. 확인해줘. 분석 조사 등으로 해봐'
> 상태: 시안 ㉠ = 게임에 들어 있으나 기본은 지금 모습(`?skillfx=card`로 봄) — 기본으로 넣을지 답 대기. 개발 로그 = CHANGELOG 354.

## 1. 지금 어떻게 보이나(실측)

싹둑마마 대 프로스트벨 세 턴을 장마다 찍어 무엇이 언제 어디에 뜨는지 기록했다(`tools/shots/skillfxcompare.mjs`).

| 무엇 | 모양 | 자리 | 시간 |
|---|---|---|---|
| 기술 이름 | 어두운 둥근 띠(속성 빛이 옅게) + 흰 글자가 한 자씩 · 그림 없음 · 높이 17 | 쓰는 식물 머리 위 | 그 기술 단계 동안(1.3 ~ 2.4초) |
| 상태 이상(효과 조각) | 어두운 둥근 칩 + 상태 아이콘 + 이름(+ 겹) · 높이 15 | 걸린 식물 머리 위 → 효과 칸으로 날아가 꽂힘 | 0.7 ~ 1.15초 |
| 판정 낱말(스침 · 메아리 · 버팀! · 먼저!) | 색 글자만 | 그 식물 머리 위 | 약 1초 |
| 피해 숫자 | 굴러가는 큰 숫자 | 맞은 식물 위 | 약 1초 |

헷갈리는 까닭:
1. 기술 이름과 상태 이상이 둘 다 '식물 위에 뜨는 어두운 작은 상자 + 짧은 글자'다. 모양 · 색 · 크기가 거의 같고 다른 점은 아이콘 하나뿐이다.
2. 버프 · 자세 기술은 쓰는 식물과 걸리는 식물이 같아, 같은 머리 위에 기술 이름 → 효과 조각이 이어 뜬다(아침이에요. → 아침).
3. 기술 이름이 문장(아침이에요. · 깨트려드리죠. · 무릎 꿇어라)이라 글만 보면 대사나 상태와 구분이 안 된다.
4. 이 게임에서 기술 = 손패 카드인데, 쓸 때 카드 그림이 나오지 않아 '카드를 썼다'는 연결이 없다.

## 2. 다른 게임은 어떻게 나누나

- **턴제 RPG**(파이널 판타지 · 옥토패스 트래블러 · 다키스트 던전): 기술 이름은 이름 상자나 띠로 따로 보여 주고, 피해 · 상태는 맞은 쪽 머리 위에 떠오르는 글자로 보여 준다. '누가 무엇을 썼나'와 '무엇이 일어났나'를 다른 그릇에 담는다.
- **카드 게임**(하스스톤 · 슬레이 더 스파이어): 쓴 카드를 카드 그림 그대로 크게 보여 주거나 버린 더미로 날려 보낸다. 기술 = 카드 모양이라 상태 아이콘과 헷갈릴 일이 없다.
- **라이엇 [Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)**: 정보 종류마다 다른 모양을 쓰고, 눈길은 중요한 만큼만 끈다. 색 하나만으로 나누지 않는다(효과 표시 = 아이콘 + 글자 — 밤샘 b 연출 조사와 같은 근거).

정리: 기술과 상태를 **그릇(모양) · 밝기 · 크기**로 나누고, 이 게임에서는 기술의 그릇을 **카드**로 하는 것이 가장 자연스럽다.

## 3. 시안 ㉠ — 기술 = 카드 + 밝은 이름 띠

- 이름 띠 바깥쪽 끝에 그 기술 카드(손패와 같은 앞면, 22×30)를 붙인다. 내 식물은 왼쪽 끝, 상대는 오른쪽 끝이다(상대 띠 왼쪽은 상대 체력판에 가려진다). 상대 띠는 오른쪽 위 카드 더미에 안 닿게 조금 내린다.
- 띠는 속성 색으로 밝게, 글자는 한 칸 크게(11 → 13), 띠 높이는 17 → 20.
- 상태 이상(효과 조각)은 그대로 둔다. 결과: **밝은 띠 + 카드 = 기술**, **어두운 칩 + 아이콘 = 상태**.
- 보기: 게임 주소 뒤에 `?skillfx=card` · 비교판 = 이 폴더 `pair_6800.png`(내 무릎 꿇어라) · `pair_14100.png`(상대 깨트려드리죠.) · 영상 = `node tools/shots/skillfxcompare.mjs <폴더> 3900 18300`.
- 기본으로 넣으려면 `v2/src/scenes/battle.js` SKILLFX 기본값만 'card'로 바꾼다.

## 4. 같이 바뀐 것(기본으로 들어감)

- 상대가 쓴 카드는 그 기술과 걸린 효과가 끝나고 다음 차례가 시작될 때 바로 식물에서 튀어나와 더미로 간다(CHANGELOG 353 — 사용자 '사용 후 더미로 가는 연출 줘'). 시안 ㉠과 함께 보면 '쓴 카드가 띠 끝에 보임 → 끝나면 더미로'가 이어진다.
