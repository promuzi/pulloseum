# 효과 대분류 · 지속·해제 조건 통합표 (2026-10-19)

사용자가 제시한 버프/디버프/상태이상/준비/스킬/환경/함정/소환수 틀에 기존 공통 효과와 설계 받은 종 효과를 대조한다. 분류와 **방어구 → 갑주** 명칭 변경은 이번 사용자 방향이며, 추가 편입/세부 해제는 추천·미결을 구별한다. [5차의 기타 목록](2026-10-19-v2-stat-status-action-framework-design.md)과 [공통 은신](2026-10-19-v2-unified-stealth-design.md)의 앞선 결정을 이어받는다. **문서만 변경하며 게임 코드/배포는 변경하지 않는다.**

## 1. 사용자 원문

## 2. 읽는 기준

- 대기 효과의 이름은 **준비 효과**를 추천한다. 사용자가 적은 집중/은신/반사/보호막을 그대로 묶고, 시간만으로 소멸하지 않는 이전 방향과 1회성 소비를 연결한다. '1회분'의 단위는 효과별로 정해야 한다.
- 기술과 남는 효과를 구별한다. 예를 들어 정화는 실행하는 스킬이고, 재생을 주는 스킬이 만든 지속 효과는 이로운 상태이상이다. 기술 하나가 공격과 여러 효과를 함께 만들어도 같은 효과를 두 종류로 중복 등록하지 않는다.
- 표에서 **추가안/안/미정**은 이번 표만으로 확정하지 않는다. 기존 피해량/기간/속성 상호작용은 이전 기록을 보존하며, 표는 새 분류를 실제 코드에 적용했다는 뜻이 아니다.
- 버프는 앞선 결정대로 겹별 독립 만료/장기 또는 무기한/교체 보존. **디버프는 순수 능력치 감소라는 분류만 이번에 정해졌고, 중첩·기간·교체까지 버프와 같다고 자동 확정하지 않는다.**
- 분노/가속/만개/칼춤이 주는 강화는 공격/기동/방어 등 공통 능력치 버프에 대응시킨다. 독립 만개 상태를 줄이는 앞선 안과 사용자 기술 이름/기존 수치 보존을 유지한다.
- 젖음/빙결/감전처럼 자체 연계가 있는 상태는 부가 수치 감소가 있어도 그 상태 하나로 보존한다. 젖음 하나를 별도 방어/기동/정확도 디버프 세 개로 쪼개 정화나 타이드의 종류 수를 늘리지 않는다.
- 표의 물/불 해제는 명중한 공격의 기존 상호작용이며, 해당 불 기술이 같은 상태를 직접 새로 거는 경우 자기 효과를 태우지 않는 기존 예외도 보존한다. 속성 연계의 별도 개편은 이번 분류만으로 하지 않는다.

## 3. 대분류부터 해제 조건까지 한 표

아래 한 표가 사용자 틀의 정리표다. 체력 제외 능력치의 예는 공격/방어/기동/치명 확률/정확도이며, 새 기본 능력치를 추가하는 것까지 확정하지 않는다.

| 대분류 | 중분류 | 소분류 | 해당 항목/효과 | 지속·중첩 | 해제·종료 조건 |
|---|---|---|---|---|---|
| 버프 | 능력치 강화 | 체력 제외 | 공격력/방어력/기동성/치명 확률/정확도 증가 | 장기 또는 무기한. 겹마다 기간 독립, 교체 보존 | 각 겹 만료. 강화 제거 스킬의 대상 범위는 미정 |
| 디버프 | 능력치 약화 | 체력 제외 | 같은 능력치의 감소. 약화=공격 감소/부식=방어 감소/교란의 순수 수치 부분 편입안 | 중첩·기간·교체 미정 | 정화 대상에 포함하는 안. 수치별 한 종류로 셀지 명시 필요 |
| 상태이상 | 해로운 | 데미지 | 화상 | 횟수·기간형. 피해량/회복 감소 차별화 미결 보존 | 정화/기간 종료. 물 공격에 꺼지는 기존 상호작용 보존 |
| 상태이상 | 해로운 | 데미지 | 독 | 겹형. 기존 5겹/미갱신 시 자연 감소는 재검토 전 기록 | 정화/겹 감소로 0. 물에 꺼지는 화상 규칙을 적용하지 않음 |
| 상태이상 | 해로운 | 데미지 | 출혈 | 유한 지속안. 독립 중첩 여부는 기존 차별화 논의와 함께 미정 | 정화/기간 종료안. 물 공격만으로 없애지 않는 안 |

| 상태이상 | 해로운 | 비데미지 | 덩굴/젖음 | 덩굴은 기술 제한, 젖음은 복합 방해·연계. 각각 유한 기간 | 정화/기간 종료. 불 피격에 덩굴·젖음이 풀리는 기존 상호작용 보존 |
| 상태이상 | 해로운 | 비데미지·추가안 | 기절/마비/얼음/매혹의 행동 취소 | 다음 해당 행동 1회 취소. 선공·후공에 따라 이번 또는 다음 행동 | 행동 취소를 소비하면 종료. 취소 판정 전 정화 가능 범위/면역 대상은 구체화 필요 |

| 상태이상 | 해로운 | 비데미지·추가안 | 그늘/숨막힘 등의 햇빛 방해 | 턴 끝 햇빛 획득을 막는 기존 효과 | 해당 턴·기간 종료/정화안. 둘을 한 효과로 통합할지는 미정 |

| 상태이상 | 해로운 | 조건부·추가안 | 기생 씨앗/지속 흡수 연결 | 적에게 피해를 주고 연결된 쪽을 회복. 유한 횟수 | 정화/횟수 소진/불 피격. 관계의 어느 쪽이든 교체 시 연결 종료하는 앞선 안 보존 |
| 상태이상 | 해로운 | 조건부·추가안 | 타들어가는 갈망/불씨의 화상 강화 부분 | 화상·대면 조건이 유지되는 동안 정해진 기간 | 정화/기간 종료/화상 또는 대면 조건 종료안. 불씨 첫 불 공격은 스킬 처리 |

| 소환수 | 희생형 | 대신 맞기 | 가이아 희생의 성체/희생체 | 별도 체력·방어를 가진 개체. 수명 없음 | 체력 0/주인 퇴장/다른 성체로 교체. 유지비형만 지불 불가 시 소멸. 일반 정화로 본체 삭제 불가안 |

## 4. 같은 분류로 옮길 때 놓치면 안 되는 것

1. **정화의 새 범위:** 버프와 디버프가 순수 수치 변화로 좁혀졌으므로 '디버프 제거'만 적으면 화상/기절을 빠뜨린다. **디버프와 해로운 상태이상 제거**라고 적는 안을 추천한다. 기본 2종/전문 전체/무작위 추첨 결정은 보존하되 같은 수치의 여러 겹을 한 종류로 셀지, 한 번에 전부 지울지는 아직 미결이다. 버프/이로운 상태/준비/갑주/환경/함정/소환수를 '전체'라는 말로 함께 지우지 않는다.
2. **면역과 의지:** 면역은 명시한 효과를 기간 동안 확정 차단, 의지는 저항 확률 증가라는 차이다. 기존 코드의 '버팀'은 재기절뿐 아니라 빙결/감전의 행동 취소도 막으므로, 앞의 대화에서 기절만 막는 것처럼 설명한 부분을 정정한다. 이번 표에서 그 범위를 임의로 줄이지 않는다. 연속 행동 취소 방지용 자동 면역을 적이 지울 수 있는지도 별도 결정해야 한다.
3. **복합 상태/연결:** 포자는 발동 전 피해가 없고 기생 씨앗은 대상 피해와 다른 쪽 회복을 함께 만들어 조건부에 넣는 안이다. 기생 씨앗 하나를 적의 데미지 상태와 내 재생 두 개로 복제하지 않는다. 갈망/불씨의 정화 가능 부분과 환경/패시브에서 다시 계산되는 조건도 구별한다.
4. **갑주:** 이번 명칭 변경은 설계 용어에 반영한다. 코드의 내부 식별자나 사용자 원안 인용/옛 수치표를 일괄 바꾸지 않는다. 스킬로 갑주량을 채우는 것과 지속 상태이상을 새로 거는 것은 별개다.
5. **준비 1회분:** 집중/반사/은신은 발동으로 소비하는 방향이나, 보호막은 남은 양이 있는 기존 방식과의 정리가 필요하다. '1회성'이라는 문구만으로 연타 한 타마다 모든 보호량을 없애거나 무기한 반사를 허용하지 않는다.
6. **원천과 부여 효과:** 성체/환경/패시브가 있는 동안의 능력치 보정은 매 턴 독립 영구 강화 겹을 쌓는 것으로 바꾸지 않는다. 원천이 끝나면 원천 보정도 끝나는 기존 방향을 유지한다. 원천의 직접 피해와 적에게 별도로 부여한 화상도 구별한다. 소환수에게 걸린 상태를 정화하는 것이 소환수 자체를 없애는 것은 아니다.

## 5. 기존 기타에서 새 분류에 편입 가능한 것

| 기존에 별도로 뺀 것 | 이번 틀에서의 자리 | 편입 조건/남는 결정 |
|---|---|---|
| 순수 공격/방어/정확도/기동 감소 | 디버프 | 약화/부식/교란의 독립 효과 이름을 수치별 효과로 줄이는 안. 겹·정화 기준 정리 필요 |
| 연속 기절 방지 버팀/스킬로 주는 예방 보호(옛 정화 보호) | 이로운 상태이상 > 비체력 > 면역 | 자동 면역의 보호 범위와 제거 가능 여부 보존/재정의. 선천적 속성·카드 면역의 원천은 패시브로 남김 |
| 지속 씨앗 흡수/포자/갈망·불씨 연동 | 해로운 상태이상 > 조건부 | 대상·연결·종료 규칙 명시. 지옥의 주민이라는 단순 화상 여부 판정은 기술/패시브의 조건식으로 두고 새 상태로 중복 생성하지 않음 |
| 시한 폭발/메아리/모으기/그 턴 방어·회피·죽은 척 | 스킬 > 예약·반응 처리 | 정해진 시각/그 턴 유효 범위 보존. 사용자 1회성 무기한 준비와 자동 통합하지 않음 |
| 정화/치유의 물/윤회/청산/업화/조화/훔치기 | 스킬 > 제거·복사·소비 | 시전 행동의 분류는 해결. 무엇을 대상으로 세고 지울지는 새 분류 기준으로 다시 적기 |
| 한 공격의 관통/확정 명중/확정 치명/즉시 흡수 | 스킬 > 공격의 성질 | 별도 지속 상태를 만들 필요 없음. 여러 턴 관통을 주는 효과까지 자동 편입한 것은 아님 |
| 강풍/지옥/비/바람길/눈보라 | 환경 | 사용자가 만든 환경 분류에 편입. 기존 초안 환경의 채택은 별도 |
| 쏜위드 덫 | 함정 | 공유/소유/폭발/소비 규칙은 기존 확정·제안 구별 유지 |
| 가이아 희생 성체/독립 희생체 | 소환수 | 본체 소멸과 소환수에게 걸린 상태 제거는 다른 처리 |
| 가이아의 나머지 성체: 철벽/모래성/회복/지옥 요새/움직이는 성 | **기존 기타 중 편입 보류** | 별도 체력·피격 대상이 없는 원천형 시설. 소환수를 **소환물**로 넓혀 개체형/설치형을 두는 안 추천. 현재 틀 그대로면 설치물로 보류. 수명 없음/주인 교체 시 철거/유지비 결정은 보존 |
| 일시 철벽의 직접 피해 감소 | **기존 기타 중 편입 보류** | 능력치 밖의 배율. 방어력 강화로 통합하거나 이로운 비체력 상태 '피해 경감'으로 남기는 안. 계산이 달라 어느 쪽도 자동 확정하지 않음 |

## 6. 기존 기타를 제외하고 새로 남는 후보

| 아직 그대로 넣기 어려운 것 | 남는 이유 | 정리 후보 |
|---|---|---|
| 불타는 의지 | 다음 검방술 **2회**라는 기존 설계로, 이번 준비 효과 **1회성**과 그대로 맞지 않음. 새 '의지' 저항 상태와도 효과가 다름 | 준비 효과를 '정해진 횟수 소모형'으로 넓히거나 이 기술을 1회로 재설계할지 선택. 기존 2회를 조용히 1회로 바꾸지 않음 |

앞의 일반 성체/직접 피해 감소는 이미 5차 별도 목록에 있던 것이므로 '기존 기타 외 새 잔여'로 중복 계산하지 않는다. **이 대조 범위에서 새로 걸리는 것은 불타는 의지 1묶음**이다. 이번에 삭제하지 않으며, 없애면 페탈로즈 원안의 속성 대응 수단이 사라진다. 효과 처리 통합과 기술 삭제를 구별한다.

**기존 기타에 그대로 남길 것:** 전기/허세·위축 등 고유 자원·모드, 충전 정지/사용 횟수/일반 교체 대기시간/선공·명중 불운 보정 등 전투 기록, 카드/타고난 패시브/기초 능력치. 이번 '새로 안 맞는 것' 목록에 이들을 다시 섞지 않는다. 패시브가 부여한 실제 재생/강화는 해당 효과 분류의 처리를 쓸 수 있지만, 패시브 자체를 정화 가능한 상태로 바꾸거나 매 턴 영구 겹을 추가하지 않는다.

## 7. 범위

대조 범위는 현재 공통 효과/장치와 사용자 설계 받은 종 1~9, 앞선 은신 통합에 직접 해당하는 그림자 분신이다. 10~46번의 미승인 종 초안 전체를 확정하거나 새 생물/상태를 창작해 채우지 않는다. 기본 표에 들어간 추가안/범위/이름과 기존 기타의 편입 보류 2묶음/새 잔여 1묶음을 다음 논의 대상으로 남긴다. 코드/저장 형식/리그전/배포는 수행하지 않는다.
