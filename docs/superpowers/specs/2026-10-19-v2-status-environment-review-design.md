# 출혈 · 정화 · 환경 · 설치물 검토 (2026-10-19)

사용자가 보낸 5~9번 종 설계와 공통 효과의 초기 검토 기록이다. **최신 결정/추천은 [상태·교체·연계 3차 검토](2026-10-19-v2-status-switch-combo-review-design.md)**를 따른다. 정화 두 단계/일반 환경 무제한·지옥 진영당 1회/설치물 수명 없음 등은 사용자 결정이다. 화상 회복 감소 제거는 설계 선택이며, 새 피해량(화상 5%/출혈 2%)/교체 처리/불씨 최초 점화·푸른 환경은 새 추천으로 구별한다. 아래 초기 수치/제안이 최신을 덮지 않으며 코드에는 아직 적용하지 않았다. 종별 원안은 [종 고유 기술 §5~9](2026-10-18-v2-species-skills.md).

## 사용자 공통 효과 원안

```text
- 출혈: 디버프이며, 화상처럼 턴을 샘. 지속피해와 회복방해가 존재. 가시나 베기 등에 좋을 듯
- 정화: 모든 디버프가 사라지는 거라면 갯수를 조절할까 고민중
- 환경: 버프와 디버프처럼 해제하지 못하며 전투중인
맵에게 영향을 주는 효과임. 턴을 기다리지 않는한 사라지지 않음. 모두에게 적용일지 적만 적용할지도 달라짐. 가이아룩과 블레이드블룸의 스킬을 보고 판단해보자. 얘는 다시 그 환경 스킬을 써도 갱신되지 않음? 고민해보자. 강풍을 여기에 넣을까 싶음
```

공통 문장의 '블레이드블룸'과 이번 종 제목 '블레이즈블룸'은 표기가 다르다. 같은 대상을 가리킨 것으로 잠정 연결하되 원문을 고치거나 새 종을 만들지 않는다. 종 제목 '앰버캑터' · '가이아룩'도 기존 데이터의 '엠버캑터' · '가이아록'과 연결하되 정식 이름 변경은 미결이다.

## 1. 현재 규칙과 이번 제안을 구별

- 현재 화상: 턴 끝 최대 체력 4%씩 3회, 받는 회복 50%. 불 속성은 화상 면역. 물 공격에 **맞은 대상**의 화상이 꺼진다. 자신이 물 공격을 쓴다고 자신의 화상이 꺼지는 것은 아니다.
- 현재 감전: 자기 차례마다 25%(젖으면 50%) 마비, 마비되면 감전이 풀린다. 번개 속성은 감전 면역. 빙결은 여전히 3겹이면 한 번 쉰다.
- 한 번 쉰 다음 턴의 버팀은 유지한다. 확정 기절 · 확정 마비도 이를 무시하지 않는다. 한 행동에서 빙결과 기절을 동시에 충족해도 두 차례를 빼앗지 않는다.
- 현재 덩굴(`bind`)은 기술 하나 봉인, 뿌리 묶기(`root`)는 교체 금지다. 이번 타이드바인의 두 기술에서 각각 구별해야 한다.
- 현재 공통 정화는 모든 일반 디버프 제거 + 다음 턴까지 새 디버프 방지다. 아쿠아벌브의 치유의 물 · 윤회는 별도의 사용자 확정 설계이므로 이번 고민만으로 약화하지 않는다.
- 실제 교체는 `FX.keep`인 화상/독뿐 아니라 방어구/만개도 보존한다. 대신 맞기는 실제 교체와 다른 피격 대상 변경으로 설계하며 교체 정리를 실행하지 않는다. 대기석 상태 지속/피해는 [후속 §4](2026-10-19-v2-species-followup-design.md)에서 별도 제안으로 구별한다.
- 현재 경기장 장치는 판 전체 한 칸이며 새 효과가 이전 것을 덮고, 같은 효과도 다시 쓰면 남은 시간이 새로 잡힌다(`devices.js setField`). 이번 사용자의 '시간을 기다려야 사라짐' · '재사용 갱신 여부'와 다르므로 **새 제안이 이미 구현되어 있다고 쓰지 않는다**.

## 2. 출혈 제안

**2차 설계 선택:** 화상에서 회복 감소를 빼고 출혈에만 회복 감소를 남긴다. 화상은 4%×3회 순수 지속 피해, 출혈은 아래 3%×3회/회복 50% 감소/중첩 없음으로 구별한다. 현재 게임 코드는 여전히 화상 회복 감소가 있다.

- 턴 끝 **최대 체력 3%씩 3회**, 받는 회복 **50%**. 중첩하지 않고 다시 걸면 남은 횟수를 3으로 되돌린다. 사용자가 말한 지속 피해 · 회복 방해는 유지한다.
- 화상과 별개의 디버프 한 종류다. 화상 + 출혈이면 턴 끝 7%, 회복 50% 감소는 출혈에서만 온다. 화상은 회복량에 영향을 주지 않는 새 설계다.
- 화상과 달리 속성 공통 면역을 새로 붙이지 않는다. 정화로 제거 가능하며 방어구를 통과하고, 반사를 다시 일으키지 않는 지속 피해로 제안한다.
- 3:3 교체 시 남은 횟수를 가지고 따라가는 안을 추천한다(화상과 같은 지속 피해 계열). 위 네 줄 모두 아직 제안이다.
- 가시 · 베기 기술에 자동으로 출혈을 붙이지 않는다. 개별 기술에서 채택 여부와 대가를 정한다.

## 3. 정화 제안

| 선택 | 장점 | 대가 |
|---|---|---|
| 모든 정화를 지금처럼 전부 제거로 유지 | 읽기 쉽고 디버프 몰아넣기에 확실한 대응 | 값싼 복합 정화 기술 하나가 여러 종의 준비를 지움 |
| **일반 정화 2종류 / 전문 정화 전부 제거** | 가벼운 정화와 아쿠아벌브의 전문성이 구별됨 | 부분 정화에서 무엇을 지울지 규칙이 필요 |
| **부분 정화에서 종류별 무작위 추첨** | 사용자 선호. 고정 순서로 특정 효과가 늘 남는 문제를 줄임 | 중요한 효과가 남을 수 있어 전체 제거와 구별됨 |

추천은 둘째다. 독 5겹도 '독 한 종류', 빙결의 겹도 한 종류로 센다. 일반 정화의 기존 추가 효과인 '다음 턴까지 디버프 방지'는 이번에 없애자고 제안한 것이 아니다. 실제 적용 전 해당 보호까지 포함해 비용을 확인해야 한다.

**종류별 균등 무작위 2종, 중복 추첨 없음**은 후속 사용자 '추천대로'로 동의됐다. 독 겹 수에 비례해 추첨권을 늘리지 않으며 2종 이하면 전부 제거한다. 기술마다 제거 수를 제각각 둘지는 추가 논의 중이며, 기본 2종/전문 전체의 두 단계만 추천한다. 행동 불가(`skip` · `frozen`)는 별도 저장이므로 이를 제거할 때 한 종류로 합치고 둘 다 지워야 한다. 환경(강풍 포함) · 설치물 · 충전량 · 허세/위축 바는 정화 개수에 세지 않는다.

아쿠아벌브의 확정안 **치유의 물 = 내 디버프 전부**, **윤회 = 양쪽 버프/디버프 전부**는 그대로 둔다. 일반 정화 조정이 결정되어도 전문기까지 소급해서 두 종류로 줄이지 않는다.

## 4. 환경과 설치물 제안

| 구분 | 환경(지옥전개 · 강풍 등) | 가이아룩의 성체 |
|---|---|---|
| 붙는 곳 | 전투 지도. 시전자 진영과 영향 대상(양쪽 / 적 진영)을 기록 | 시전자에 딸린 설치물 한 칸 |
| 정화 · 윤회 · 업화 | 제거하거나 제거 개수로 세지 않음 | 제거하거나 제거 개수로 세지 않음 |
| 다시 쓰기 | **같은 진영의 같은 종류가 살아 있으면 재사용/갱신 불가** 제안 | 다른 성체로 교체 가능. 희생의 성체 재소환은 원안대로 새 체력 |
| 끝나는 때 | 정해진 턴 수. 시전자 교체/쓰러짐으로 시간 연장을 하거나 조기 제거하지 않음 | **정기 수명 없음(사용자 결정)**. 유지비 부족/희생체 파괴/다른 성체 소환/시전자 퇴장 |

- 서로 다른 환경은 **각자 남은 시간을 가지며 공존**시키는 안을 추천한다. 하나가 다른 것을 덮으면 '해제 못 하고 시간을 기다린다'를 다른 환경으로 우회하게 되기 때문이다. 이는 현재 한 칸 장치를 바꾸자는 제안이며 확정 규칙이 아니다. 서로 모순되는 환경 조합은 종이 나올 때 따로 결정한다.
- 양 진영이 같은 종류를 쓰는 경우는 **종류+시전자 진영별 하나**로 제안한다. 상대가 먼저 지옥을 썼다는 이유로 내 지옥을 봉쇄하지 않는다. 같은 대상에 같은 종류가 겹쳐도 효과 세기는 중첩하지 않고, 각 환경의 종료 시각은 독립적으로 남긴다.
- 가이아룩은 지도 전체 규칙을 바꾸는 것보다 자기 곁에 세운 성체를 갈아 끼우는 조작이 핵심이다. 환경과 한 칸을 공유하면 지옥전개가 희생체를 지우는 등 원안에 없는 상호작용이 생긴다.
- **강풍은 환경으로 이동(사용자 결정).** 개인 디버프 정화/상태 개수에서 제외하는 방향이다. 기존 바람 기술의 비용/횟수/3:3 대상/다른 바람길과의 공존은 함께 재검토한다. 게임 코드/데이터는 아직 그대로다.
- 환경도 직접 공격하는 범위가 자동으로 광역이 되는 것은 아니다. 환경의 대상 · 지속 피해 · 특정 상태로 간주하는 조건은 각각 적는다. 불 속성의 화상 면역 같은 기존 명시적 면역을 환경으로 몰래 무시하지 않는다.
- '3턴 환경'은 펼친 턴 끝을 첫 번째로 세어 총 세 번 턴 끝에 영향을 준 뒤 사라지는 안이다. 자연 만료 이후 그 환경만으로 유지되던 상태 판정은 남지 않는다.
- 해제 불가의 리스크는 **비용/짧은 기간/갱신 금지/판당 횟수/양쪽 영향** 중 효과에 맞는 조합으로 둔다. 지옥전개는 햇빛 4/3턴/진영당 한 판 1회 제안. 약한 환경까지 자동으로 모두 같은 비용/횟수로 묶지는 않는다.

## 5. 블레이즈블룸의 지옥 판정 제안

1. **지옥의 주민**은 직접 마주한 적이 실제 화상/지옥전개 환경/불 속성 중 하나일 때 켜지는 첫 안을 추천한다. 불 속성 자동 지옥은 아직 선택 전이다. '지옥' 표시는 추가 피해나 정화 개수를 만드는 별도 디버프가 아니다.
2. 지옥전개는 적 진영의 현재 앞 식물에만 3턴간 지옥 조건을 제공한다. **새 추천은 불 상대에게 처음부터 지옥 조건을 인정하고, 현재 적이 불이면 지옥전개를 못 쓰게 하기**다. 실제 화상 피해 면역은 유지한다. 사용자 대사 '넌 이미 지옥에 있구나'를 그대로 쓴다. 이 불 상대 정책은 선택 전이며 최신 문서를 따른다.
3. 실제 화상과 환경 화상이 겹쳐도 기본 화상 피해는 턴 끝 **한 번 4%**다. **새 설계는 화상 회복 감소 없음**. 실제 화상의 남은 횟수는 정상적으로 줄고, 환경이 끝날 때 새 화상 3턴을 남기지 않는다.
4. 일반 정화의 디버프 방지 상태는 새 출혈 · 갈망 · 불씨 부여를 막는 역할을 유지한다. 이미 생긴 실제 화상은 정화할 수 있지만 지옥전개 자체는 남는다. 물 공격이나 비가 실제 화상을 꺼도 환경이 남은 동안 가상의 화상 판정은 유지되는 안이다. 이 충돌 처리도 사용자 선택 전이다.
5. 갈망 · 불씨는 적에게 붙는 **화상 조건부 디버프**로 제안한다. 개별 정화와 업화의 대상이며, 화상 판정이 사라지거나 직접 대면이 끝나면 즉시 사라진다. 대기석에서 유지/발동하지 않는다. 지옥전개 지도 효과만은 남은 시간대로 계속된다.
6. 불씨는 사용자 수정으로 **불 공격 1회+이후 2턴 화상 피해 두 번**으로 잡는다. 새 수치 제안은 햇빛 1/불 위력 40/적중 시 조건부 추가 화상이다. 즉시 화상 1회분은 폐기한다. 출혈/독까지 두 배로 만들지 않는다. 화상 잔여 횟수는 턴 끝 한 번만 줄인다. 출혈까지 함께 쓰면 기본 4%×2 + 출혈 3% = 턴 끝 11%, 불 공격 피해는 별도다. 조건이 풀리면 이후 추가분은 끝나며 불 속성에게 화상 추가 피해는 없다.

## 6. 적용 단계에서 필요한 확인(아직 실행하지 않음)

- 자원 사용 전 충전량 검사 → 자원 지불 → 기술 실행 → 충전의 순서. 취소된 행동은 충전하지 않고 자원도 소비하지 않음. 과부하 2턴은 연타 수/효과 수에 따라 여러 번 감소시키지 않음.
- 빙결/기절/강제 마비 동시 조건에서 한 행동만 취소. 기존 버팀과 속성 면역 유지.
- 반사 → 반사 재귀 없음. 지속 피해/설치물 자동 피해를 반사 입력으로 세지 않음.
- 환경 재사용 거절 시 비용 미소모, 교체/저장 후에도 시전자 진영과 남은 턴 보존, 서로 다른 환경의 충돌 처리.
- 설치물과 환경을 윤회/청산/업화의 상태 개수로 잘못 계산하지 않음. 희생체가 받는 공격은 주인/희생체 방어를 두 번 적용하지 않음.
- 종별 리그전과 실제 저장/친구 대결 검증은 여러 종을 일괄 적용할 때 한다. 지금 숫자는 실험으로 균형이 입증된 값이 아니다.

## 7. 별도 검토에서 남긴 사용자 선택

최초 별도 검토의 선택 사항 중 **소비기 재충전 금지/공용 충전 경로/설치물 수명 없음**은 후속 사용자 결정으로 해소됐다. 환경 리스크/불 상대 지옥 조건/랜덤 정화 수/새 수치/대기석 상태는 [후속 문서](2026-10-19-v2-species-followup-design.md)를 따른다. 앰버캑터는 위축 중 기고만장 사용 가능/호소하기 바 이동/기고만장 비용 변화가 사용자 결정이며, 새 비용/위력/기절 확률표는 제안이다.
