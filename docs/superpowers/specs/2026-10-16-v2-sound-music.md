# v2 소리 — 효과음 · 배경 음악 (2026-10-16)

사용자 "효과음은 만들면서 노래도 함 고려해줘 — AI로 만드는 게 나을지, 그럼 어떤 방식이 좋을지도 조사해줘" · "전등의 깜빡임이나 여러 장면 변환 등 효과음을 적절히 적용해줘".

## 1. 지금 들어간 것
- **효과음 = 코드가 그 자리에서 만듦**(`v2/src/core/sound.js`, 소리 파일 0개). 레트로 효과음 도구(sfxr · ZzFX)와 같은 방식 — 파형 하나(사각 · 펄스 12.5%/25% · 세모 · 사인 · 톱니 · 잡음)에 높낮이를 미끄러뜨리고 짧게 사라지게 + 거름망. 우리 코드로 짜서 저작권 · 파일 크기 걱정 없음.
- 붙인 곳: 단추 누름(바탕 막이 제외) · 카드 고름/못 씀 · 카드 뒷면(꾹) · 기술 이름 리본(휙) · 먼저 · 맞음(빗나감 · 스침 · 정타 · 많이 깎으면 묵직 · 치명) · 효과 굉장 · 막음 · 자세 · 쓰러짐 · 승리/패배 가락 · 시간 막대 10초부터 초마다 똑(3초부터 높게) · ㉣ 굴림 숫자가 도는 동안 따닥 → 멈출 때 딸깍 · 감정 표현 · 상태 효과 전부(화상 = 불 붙는 화르륵 + 불똥 시각마다 타닥, 독 · 감전 · 빙결 · 얼음 · 젖음 · 기절 · 포자 · 피어남 · 김 · 덩굴 · 뿌리 · 기생 · 빨아들이기 · 약화 · 도발 · 부식 · 그늘 · 강풍 · 버프 여덟) · 받은 것 판(동전) · 레벨업 상자 · **화면 바뀜**(점 페이드 = 가벼운 휙, 철 셔터 · 문 · 조리개 · 블라인드 = 닫힐 때 쾅 · 열릴 때 쉭) · **홈 전등 깜빡임**(지직 · 지지직 묶음의 꺼지는 장마다 찌직).
- **배경 음악 = 같은 방식의 칩튠 순서기**(4채널: 리드 · 아르페지오 · 베이스 · 북) — 곡은 직접 지음: 홈 = 다장조 92 · 차분(C · Am · F · G), 전투 = 가단조 150 · 몰아침(Am · F · G · Em … E), 처음 화면 = 라단조 108 · 신비(Dm · B♭ · F · C). 장면이 바뀌면 0.4초 겹쳐 넘어감, 승패가 나면 전투 음악을 끄고 가락.
- 설정 판: '효과음 켬/끔' · '음악 켬/끔'(이 브라우저에 저장). 브라우저는 사람이 한 번 눌러야 소리를 내므로 첫 누름에 켜짐. 창을 내리면 소리도 멈춤.
- 들어 보기: `node tools/shots/soundreel.mjs --out sound_reel` → `tools/shots/out/sound_reel.wav`(효과음 전부 + 음악 셋을 오프라인으로 구움). 소리 세기 점검 = 같은 파일 구간별 RMS.
- 파일 음악이 생기면 `sound.js TRACK_FILES`에 장면 → 파일을 넣으면 칩튠 대신 그 파일을 돌림.

## 2. 배경 음악 — AI로 만들까? (조사)
| 방법 | 장점 | 걸리는 점 |
|---|---|---|
| **지금처럼 코드 칩튠** | 완전히 우리 것(저작권 · 비용 0) · 파일 0 · 도트 그림과 결이 맞음 | 곡의 완성도는 작곡 실력만큼(지금 곡은 시제품) |
| **ElevenLabs Music(유료)** | 학습 데이터 사용 허락을 받은 모델 · 유료 요금제는 상업 사용 허락(방송 · 영화 · 대형 스튜디오 게임만 엔터프라이즈) · 연주곡 · 길이 지정 | 월 구독 · 프롬프트에 가수 · 곡 이름 · 가사 금지 · 소규모 인디 게임이 '스튜디오 게임'이 아닌지 약관 표에서 확인 |
| **Suno(Pro/Premier)** | 품질 좋음 · 유료로 받은 파일은 상업 사용(게임 포함) | 무료 · 체험으로 받은 곡은 비상업 · 저작권은 보장 안 함(남이 베껴도 막기 어려움) · 레이블 소송 진행 중 |
| **Stable Audio(유료)** | 허락받은 음원으로 학습 · 유료는 상업 사용(문서 확인 필요) · 오픈 모델은 매출 100만 달러 미만 조건 | 약관 · 요금 직접 확인 필요 |
| Udio | — | 최근 약관이 상업 사용 · 내려받기를 막는다는 보도 — 지금은 피함 |
| 작곡가에게 맡김 · 무료 음원(CC0) | 저작권이 깔끔 | 비용 · 찾는 시간 |

- **AI 음악의 저작권:** 우리나라(문체부 · 한국저작권위원회 생성형 AI 안내서)도 AI만으로 만든 결과는 저작물로 등록되지 않고, 사람의 창작적 기여(직접 만든 것을 입력으로 · 결과를 상당히 고침 · 고르고 배열함)가 있는 부분만 인정. 그래서 AI 곡은 '쓸 권리'는 있어도 '남이 못 쓰게 막을 권리'는 약함.
- **추천:** ① 출시 전까지는 지금 코드 칩튠을 다듬어 씀(완전히 우리 것). ② 곡 품질을 올리고 싶으면 **ElevenLabs Music 유료**로 장면별 연주곡을 만들고(상업 허락이 가장 분명), 사람이 고르고 · 자르고 · 반복 구간을 다듬어(사람 기여) `TRACK_FILES`에 넣음. ③ 효과음은 AI 말고 지금 방식 유지(짧고 반응이 빨라야 해서 코드가 더 나음).
- 구독 결제는 사용자 몫(내가 하지 않음). 만들 때 쓸 프롬프트(영문, 가수 · 곡 이름 없음):
  - 홈: "Cozy 16-bit chiptune for a space greenhouse home screen, C major, 90 BPM, soft square lead and triangle bass, gentle arpeggios, calm and warm, seamless loop, instrumental, 60 seconds"
  - 전투: "Energetic 16-bit chiptune battle theme, A minor, 150 BPM, driving pulse bass, catchy square lead, fast arpeggios, punchy noise drums, plant monster arena, seamless loop, instrumental, 60 seconds"
  - 처음 화면: "Mysterious heroic 16-bit chiptune title theme, D minor, 108 BPM, slow arpeggios, wide pad, starry space colosseum, builds gently, seamless loop, instrumental, 45 seconds"
  - 승리 · 패배 가락은 지금 코드 그대로(2초 안팎).
