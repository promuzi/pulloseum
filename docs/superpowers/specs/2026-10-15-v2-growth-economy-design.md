# v2 식물 키우기 · 기술 얻기 · 돈 · 강화 · 생장 — 논의 시작안 (2026-10-15)

> 상태: **논의 시작(구현 전).** 사용자 "되새김도 좋아 보이네 — 여러 요소 적용해서 스킬 얻는 것, 식물 키워서 돈 버는 거, 식물 업글과 생장 방법 등 여러 시스템에 손을 대보자".
> 바탕 = 확정된 것: 기술 층·효과 짝·탐사 동기 원칙(`2026-10-15-v2-skill-system-design.md` §2·§3·§5) + 옛 판 양육·열매 설계(`2026-06-24-nurture-fruit-system-design.md` — 생장과 열매는 다른 축, 열매 = 시간 + 물·비료·화분, 5색 희귀도).
> v2 화면은 있음(스마트팜 · 동면 보관고 · 상점 · 가방 · 도감 · 탐사 · 정비, 식물 관리 강화 탭), 규칙·돈 흐름은 아직 시안 상태(`v2/src/data/mock.js`).

## 1. 큰 흐름(제안)
탐사 → 식물·재료 → 스마트팜에서 키우기 → **생장**(단계가 오르는 순간 기술 1~2개가 핌) · **열매**(따서 팔거나 재료) → 전투·대회 → 돈·물·비료·랭크 → **강화**(능력치) · **거름**(같은 식물로 등급 ↑) · **접목**(기술) → 다시 탐사(새 식물 · 지역 변종 · 색 변종 · 전설 · 관상용 · 열매용).
정리 = 암시장(컨셉) = **판매**(돈 조금, 무조건) 또는 **해체**(접목 기술 등 무작위, 많이 키울수록 좋은 것 확률 ↑).

## 2. 생장(진화) — 어떻게 자라나
| 안 | 자라는 힘 | 단계가 오르는 순간 |
|---|---|---|
| 가. 전투만(옛 판) | 전투 경험치 | 자동 |
| 나. 전투 + 돌봄(추천) | 전투 경험치 + 물·비료 주기 + 열매 수확 | **내가 누름**(진화 연출 → 그때 기술이 핌) |
| 다. 나 + 재료 | 나와 같음 | 마지막 단계만 '생장 촉진제'(탐사·열매) 필요 |
- 추천 = 나(+ 다는 마지막 단계만): 키우는 손맛(돌봄)과 싸우는 손맛이 둘 다 생장으로 이어지고, 기술이 피는 순간을 내가 고름.
- 가꾸는 대로(C): 그 단계 동안 준 **비료 종류**가 피어날 기술 쪽을 조금 기울임(불 비료 → 불 상급 쪽) — 숨긴 채로도 내 손이 닿는 위험 관리.

## 3. 기술 얻기(여러 길)
1. **피어나기:** 단계가 오를 때 1~2개(그 식물이 배울 수 있는 것 중 무작위 — 상급은 미리 안 보임). 칸이 차 있으면 **이전 기술을 지우고** 배움.
2. **접목:** '접목 가지'(아이템)를 붙이면 그 기술을 배움(속성·종·생장이 맞아야) — 포켓몬 기술머신처럼. 얻는 곳 = 해체 · 탐사 · 대회 보상 · 주황 열매.
3. **되새김:** 지웠거나 놓친 기술을 다시(돈 또는 재료).
- 정할 것: 식물이 **기억하는 기술 수**. 추천 = 전투 칸만큼(포켓몬의 4개처럼 꽉 차면 지우고 배움) → 지금 전투 칸 = 기본기 셋 + 기술 셋(3:3은 마지막 칸이 교체라 교체 단추를 다른 자리로 빼야 함).

## 4. 식물로 돈 벌기
| 길 | 내용 | 맞는 식물 |
|---|---|---|
| 열매 판매 | 열매를 따서 팔기(희귀할수록 비쌈) | 열매용(열매 많고 값 ↑) |
| 의뢰 납품(제안) | 게시판 주문 "다 자란 불 식물" · "꽃 핀 관상용" · "색 변종" → 돈 + 보상 | 누구나(목표가 생김) |
| 관상 전시(제안) | 관상용 식물을 탐사선·홈에 전시 → 시간마다 관람료 | 관상용(싸움은 약해도 돈) |
| 대회 상금 | 랭크·단계별 | 전투용 |
| 암시장 판매 | 무조건 돈, 대신 적게 | 남는 개체 |
- 쓰는 곳: 강화 · 되새김 · 접목 수수료 · 탐사 연료 · 화분 · 스마트팜 칸 · 꾸미기.

## 5. 강화(업글)
- **능력치 강화(돈):** 지금 식물 관리 '강화' 탭. 제안 = 생장 단계마다 상한(어린 Lv5 · 자라는 Lv10 · 다 자란 Lv15) → 생장해야 더 강해짐.
- **등급(거름, 확정):** 같은 식물을 먹여 D → C → B → A → S, 능력치 차이는 작게(±5% 안팎).
- **화분:** 양육 전용(열매 속도·개수) — 옛 판 그대로.

## 6. 탐사 서브 재미(확정 방향, 세부 제안)
- **전설:** 행성마다 하나, 특별 조건(시간 · 날씨 · 탐사선 장비)에서만, 아주 드묾.
- **색 변종(포켓몬 이로치처럼):** 아주 낮은 확률, 겉모습 색만 다름 → 판매가 · 전시 가치 ↑.
- **관상용 · 열매용:** 싸움 대신 돈·재료로 값어치.
- **지역 변종:** 같은 식물도 행성마다 곁속성 · 가지 기술이 다름.
