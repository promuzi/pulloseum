| 항목 | 지금 | 바꾼 뒤 |
|---|---|---|
| 방어력 | 빼기: 위력 × 공격 ÷ 50 − 방어 × 0.5, 최저 25% | **비율: 받는 비율 = 100 ÷ (100 + 방어)**, 막는 양 상한 75% |
| 관통(새 능력치) | 없음 | 상대 방어의 일부를 무시(예: 찌르기 30%) — 방어태세의 천적 |
| 방어 자세 | 후공일 때만, 받는 피해 40% | **방어태세**: 순서 무관, 이번 턴 방어 ×4, 맞으면 무너짐(기본 1타 · 기술마다 n타) |
| 방어구(새) | 없음 | 체력 위에 따로 쌓이는 금속 칸 · 깨질 때까지 · 상한 최대 체력 50% · 망치(타격)에 약함 · 지속 피해는 통과 |
| 보호막 | 최대 체력 15%, 3턴 | 그대로. 막는 순서 = 보호막 → 방어구 → 체력 |
| 회피 자세 | 빗나감 +22 · 스침 +14(평균 −35%) | 턴 전체 모든 타 · 빗나감 +15 · 스침 +10(평균 −25%) |
| 은신(새) | 없음 | 이번 턴 · 광역 아닌 공격 95% 빗나감 · 무조건 나중에 움직임 · 기습(위력 ×1.5, 상대 자세 무시) · 은신끼리는 회피 상쇄, 나중에 움직인 쪽만 기습 |
| 분신(새) | 없음 | 2턴 · 광역 아닌 공격 90% 빗나감(분신 수와 무관) · 진짜가 맞거나 광역에 맞으면 풀림 · 판마다 횟수 |
| 광역 | 회피 자세 절반만 | **확정 명중**(빗나감 · 스침 없음, 치명은 있음) · 위력은 단일의 85% |
| 연타(새) | 없음 | 타마다 따로 판정 · **불운 보정 없음** · 효과는 첫 적중 때 한 번 · 반사는 타마다 |
| 연타 + 쌓이는 효과 | — | 독 · 빙결 · 포자를 타마다 거는 기술만 따로 표시: 비용 +1 · 타 위력 −25% · 한 기술로 최대 +3겹 |
| 감전 | 3겹 = 마비 | 화상처럼 3턴(다시 맞으면 새로) · 자기 차례마다 25%(젖으면 50%) 마비 → 마비되면 감전 풀림 · 쉰 다음 턴 버팀은 그대로 |
| 평타 위력 | 40 | 30(방어 공식이 작은 타를 덜 깎게 되어 보정) |

- 숫자 확인(공격 34 기준): 위력 105 한 방 = 방어 22에 60 → 59 · 방어 37에 53 → 52(거의 그대로) / 위력 21 × 5타 = 18 → 59(한 방과 같아짐) / 평타 40 = 16 → 22 · 9 → 20.
- 방어태세 효과: 방어 22 = 47% · 방어 37 = 60% 막음 → 단단한 식물이 더 잘 막는다. 방어태세가 '맞으면 무너짐'이어야 연타가 방어의 천적으로 남는다.
- 손익: 방어태세 감소(47~60%) ÷ 회피 감소(25%) ≈ 2~2.4 → 3타 이상 연타엔 회피가, 한 방엔 방어가 낫다.
- 은신 · 분신 확률은 판정표의 빗나감 상한(70%) **앞에서** 따로 굴린다.
- 고리: 큰 한 방 → (막힘) 방어태세 → (뚫림: 연타 · 관통) → 연타 → (피함) 회피 · 은신 · 분신 → (확정) 광역 → (위력이 낮아 막힘) 방어태세.
- 결정 로그에서 바뀌는 것: '방어는 후공일 때만'(2026-10-15) → 순서 무관 · '빙결 · 감전 3이 되면 쉼'(2026-10-15) → 감전만 확률형.
- **구현 현황:** 1단계(방어 비율 · 평타 30 · 회피 −25% · 광역 확정 + 0.85 · 감전 확률)는 친구 서버 반영됨(CHANGELOG (83), `RULES_VER` 2). **2단계 방어태세**(CHANGELOG (84), `RULES_VER` 3): 순서 무관 · 방어 ×4 · 기본 적중 1회 후 해제, 스침·보호막 흡수도 적중으로 셈. 빗나감은 소모하지 않음. **2단계 나머지 = 방어구 · 관통 · 연타 · 은신 · 분신 · 순서 손잡이(먼저 · 나중) 들어감**(CHANGELOG (86), `RULES_VER` 4, 시험 `tools/test/devices.mjs`) → **바닥 규칙 끝. 다음 = 공통 장치(§2) · 종 기술(species-skills).** 실행·검증 기록 = `C:\dev\pulloseum\docs\superpowers\plans\2026-10-18-v2-guard-stance.md`.
- **기존 규칙 보존 판단(코덱스, 새 사용자 결정 아님):** 치명 → 정타 유지. 연속 자세의 추가 효과 절반 유지(방어 +300% → +150%, 최종 ×2.5). 방어 배율은 방어 상한 75% 적용 전에 계산하고 원래 능력치를 덮어쓰지 않는다. `guardHits`는 기본 1이며 연타 해소는 다음 작업에서 연결한다.

## 4. 기술 세트 상세
### 팽트랩 — 식사시간 · 맛평가(사용자 결정)
| 기술 | 햇빛 | 위력 | 효과 |
|---|---|---|---|
| 입맛 다시기 | 1 | — | 상대 약화 + 내 변이 기술 위력 +20%(2턴) · 준비 +1 |
| 소화액 분비 | 1 | 50 | 멀리 · 독 1겹 + 방어 감소 · 준비 +1 |
| 물어뜯기 | 1 | 65 | 찌르기(관통 30%) + 방어 감소 · 준비 +1 |
| **식사시간**(옛 '집어삼키기') | 3 | 90 | 준비 수(0~3, **같은 기술 중복 가능**) → 추가 피해 0 / +20 / +45 / +80% · 흡수 20 / 35 / 50 / 70% → 준비 0 · **'식후' 표식**(넣은 준비 수를 기억) |
| **맛평가**(팽트랩만) | 0 | — | 식후가 있을 때만: 0 = 퉤(없음) · 1 = 그럭저럭(약화) · 2 = 맛있다(약화 + 방어 감소) · 3 = 최고의 맛(+ 겁먹음 = 다음 턴 방어 · 회피 자세 금지, 지금 '도발' 규칙) · 식후 지움 |
- 식후가 사라지는 때 = 준비 기술 셋 중 하나나 맛평가를 쓸 때만(다른 기술을 쓰면 남음). 박자 = 준비 × 3 → 식사시간 → 맛평가.
- 포식 변이 카드(A안 — 사용자 "추천대로"): 옛 '물어뜯기 · 집어삼키기 · 사냥 본능' 빼고 **입맛 다시기 · 소화액 분비 · 물어뜯기 · 식사시간**을 카드로(카드 규칙 = 햇빛 0 · 판마다 횟수 — 준비 3번씩 · 식사시간 2번). 변이 식물은 전투 칸에 카드 둘까지라 '물어뜯기 + 식사시간'처럼 둘로 3준비가 됨(중복 허용이 이걸 위해). 맛평가는 카드가 아님.
- 이름 정리: 패시브 '소화액'(v_digest) → '먹잇감 노리기'(가칭) · 팽트랩 옛 '대지 집어삼키기'(u_fang_3)는 식사시간으로 바뀜.

지금(`catalog.js TIERS` · `logic.js battleReward` · `fight.js botPlant`): 단계 7(브론즈 ~ 풀로세움) × 라운드 5(예선 ~ 결승, 3승 통과 · 3패면 예선부터) · 봇은 단계가 올라도 **개체값 +단계**(0~8 + 단계, 개체값 1 = 능력치 +1%)와 변이 확률(8% + 단계 × 2%)만 오름 → 풀로세움 봇이 브론즈 봇보다 능력치 약 5% 셀 뿐. 생각(기술 고르기, `model.js aiPick`)도 같음.
제안 — 단계 9 + 맨 위 끝없는 별:
| 단계 | 봇 개체값 | 봇 강화 포인트(같은 단계 · 레벨 대비) | 봇 패시브 카드 | 봇 생각 | 목표 승률 |
|---|---|---|---|---|---|

- 풀로세움 = 결승 통과마다 별 +1(시즌 순위용). 라운드 안에서도 결승 쪽이 조금 셈.
