# v2 전투 연출 — 타격감·화면 배치 (2026-10-15)

> 사용자 지시: "게임성과 UI도 자료를 참고하면서", "각 식물별로 공격 스킬 모션과 효과". 그림·효과 도구 = `tools/pixel/big/`(대기 `--anim`, 공격 `--attack`, 변이 `--forms`).
> 지키는 기존 결정: 상대의 다음 수(종류·예상 피해)는 공개하지 않는다(PvP, 2026-09-11) · 전투 대기는 `sleep()`(2배속 절반) · 피격 순서 = 번쩍 → 히트스톱 → 넉백 → 숫자 → 체력 줄(v1 `hitFx`).

## 0. 근거
- **히트스톱:** 사쿠라이 마사히로 "Stop for Big Moments!" — 맞는 순간 잠깐 멈춰야 무게가 느껴진다, 모든 장르에 쓴다. 보스를 쓰러뜨릴 때는 더 길게(보스 스톱) → [AUTOMATON](https://automaton-media.com/en/news/20220824-15208/), [Nintendo Wire](https://nintendowire.com/news/2022/12/12/this-week-in-sakurai-12-5-12-11-fine-tuning-hit-stop-and-cheating-the-system/).
- **주스(Juice it or lose it, Jonasson·Purho 2012):** 색, 이징(가속·감속), 눌림·늘어남, 화면 흔들림, 번쩍임 — 같은 규칙에 연출만 더해도 손맛이 달라짐 → [요약](https://rpgplayground.com/research-making-a-juicy-game/).
- **스크린셰이크(Jan Willem Nijman, Vlambeer "The Art of Screenshake"):** 왜 비슷한 게임이 하나는 손맛이 좋고 하나는 나쁜가 → [Kenney 추천 영상 목록](https://kenney.nl/learn/must-see-videos-for-indie-developers).
- **도트 타격(saint11 Impact):** 대기 → 준비 → 동작 → 넘침 → 정지, 준비가 세기를 만든다, 중간 장을 빼서 빠르게, 대상이 튕기며 반응, 화면·대상 흔들기, 맞기 직전 한 장 멈춤(너무 길게는 금지).

## 1. 한 턴 시간표(1배속, 2배속은 히트스톱 빼고 절반)
| 단계 | 길이 | 내용 |
|---|---|---|
| 준비 | 0.30초(6장) | 공격 쪽 뒤로 웅크림(눌림) — 기술 이름 띠가 이때 뜸 |
| 멈춤 | 0.05초(1장) | 준비 정점에서 한 장 정지 |
| 동작 | 0.10초(돌진·내려치기) / 0.35초(발사체) | 잔상·바람결, 발사체는 꼬리 |
| 맞음 | 0.10초 | **히트스톱 2장**(모두 정지) + 대상 흰 번쩍 1장 + 화면 2칸 흔들림 3장 |
| 반응 | 0.40초 | 대상이 뒤로 젖혔다 복귀(밑동 고정), 피해 숫자가 튀어 오름(넘침 이징), 상성 문구 |
| 성질 | ~1.0초 | 속성 성질 표시(화상 불꽃·감전 지지직·젖음 물방울·가시·먼지·교란 소용돌이·포자) — 상태 아이콘이 붙는 순간과 맞춤 |
| 체력 | 0.40초 | 체력 줄이 감속하며 줄어듦(흰 잔상 줄이 뒤따라) |
- 치명타·약점: 히트스톱 3장 + 흔들림 3칸 + 번쩍 2장(더 큰 순간만 더 길게 — 보스 스톱 원리). 마지막 일격: 0.3초 보스 스톱 + 확대.

## 2. 화면 배치(v2 전투, 논리 270×600)
- 식물은 **96×112 도트**(지금 48×56의 2배) — 무대 높이(약 348칸)에 상대(오른쪽 위)·나(왼쪽 아래)가 겹치지 않게 들어감. 정보 상자는 지금처럼 상대 = 왼쪽 위, 나 = 오른쪽 아래(포켓몬 관례).
- 효과는 **어두운 1칸 테두리**(몸·배경 어디서나 읽힘), 피해 숫자는 테두리 있는 큰 글자, 효과가 체력 줄을 가리지 않게 무대 안에서만.
- 대기: 숨쉬기 3.2초 한 바퀴 + 깜빡임 3~6초에 한 번(무작위) + 종별 특성 효과 + 변이 후광.

## 3. v2에 넣기
- ⚠ **결정 필요(사용자):** v2 무대 층은 "식물이 서 있는 장면은 2배 도트"(48×56 그림을 2배로) 구조다. 96×112 그림을 지금 화면 크기로 넣으면 식물 칸만 1배가 되어 배경(2배)과 **칸 크기가 섞인다(믹셀)**. ① 무대 배경·발판도 1배 도트로 다시 그림(추천 — 식물·효과·배경이 한 칸 크기) ② 식물만 1배(빠르지만 섞임) ③ 식물을 2배로(무대가 너무 커져 안 들어감). 정해지면 아래대로 넣는다.
- 그림: `node tools/pixel/big/export.mjs` → `assets/v2/plants/<키>_idle.png`(64장 시트, 식물만 투명) + `<키>.json`(장 크기·시간·눈 좌표) + 화분 `pot_terra_back/front.png`. 게임은 화분 뒤 → 식물 장 → 화분 앞 순서로 그림(흙 덮기·앞뒤 깊이는 시트에 이미 반영된 식물 칸 기준으로 게임이 같은 규칙 적용).
- 공격: 첫 단계는 종별 공격 시트(무대 그림)를 그대로 재생 → 다음 단계는 몸놀림(공격 시트)과 효과(게임 코드)를 나눠 상대 위치에 맞게.
- **무대 미리보기(2026-10-15):** 공격 영상은 이미 v2 전투 배치 그대로 굽는다(`tools/pixel/big/stage.mjs` — 나 = 받침 (76, 302), 상대 = (194, 142), 270×348 1배, ①안 모습). ①안으로 배경을 다시 그릴 때 지킬 것: 바닥·받침은 화분(pot3d)과 같은 **26° 내려다본 각도**(바닥 위 원 = 세로 0.44배 타원 — 지금 v2 받침 22×6은 0.27로 더 납작해 화분과 어긋남), 화분은 굽이 바닥에 닿는 점(`BASE_GEO`)을 받침 가운데에, 바닥을 타는 효과(갈라짐·물기둥)는 이 바닥 평면 좌표로 그리고 화분과 앞뒤를 깊이로 가린다(먼 화분 → 사이 → 가까운 화분 순).
