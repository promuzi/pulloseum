# 처음 화면 연출 + 끊기지 않는 배경 음악(세션이 이어지는 음악) — 2026-10-16

## 사용자 요청(원문)
> 배경음악과 여러 효과음을 엮고, 장소나 창이 바껴서 배경음이 조금 바뀌더라도, 끊기지 않고 자연스레 이어지게 바뀌게 만들고 싶어.
>
> 초반 화면을 바꿔줘. 검은 배경에 의자에 내 식물이 올려져 있고. 천장에서 불빛이 지지직 거리면서 켜져. 그리고 터치하면 주변 검은 배경이 밝아지는 느낌으로 대기화면으로 이어지게.
>
> 다만 대기실의 공간은 전부 디스플레이였다는 설정이므로, 디스플레이 화면이 켜지는 듯한 요소를 넣어줘. LED 하나하나 켜지는 그런거 알지? 그걸 대기실의 공간감(원형 벽과 바닥 등)을 분리해서 자연스레 넣어줘.
>
> 이때 음악에 관해서 얘기할게. 처음에는 음악단? 조율할때 나는 우우웅하는 소리처럼 검은 배경에서 점점 들리면서 화분 등장할 때쯤 자연스럽게 끝남. 그리고 전등 켜지는 소리가 두드 두드등 나면서 전등도 그에 맞게 켜짐. 근데 이게 베이스 소리같아야함. 그러면서 초반 베이스와 전등 지지직 효과가 반복되면서 리듬감을 줘. 그러가 천천히 드럼 킥이 들어오면서 강조가 되는거야.
>
> 터치하면 화면으로 넘어가면서 베이스 전등 소리에 음율이 더해지면서 서서히 다른 세션이 들어오는 걸로. 붐뱁비트처럼. 그리고 전등 지지직 효과에 맞춰 중간중간 브레이크와 함께 베이스 솔로 들어가고. 잠깐만. 그렇게 노래가 나와. 전투시작 혹은 배경음이 바뀌는 상황에는 자연스럽게 세션이 이어지며 다른 비트감과 노래로 분위기 전환. 다시 돌아올 때도 동일하게. 가능할까?

## 방향
- **하나의 지휘자(박자 격자)가 장면을 넘어 계속 돎** — 장면은 "지금 상태"(처음 · 대기 · 전투 · 결과 …)만 알려 주고, 바꿈은 다음 마디(급하면 다음 박)에 필인 · 브레이크로 이어 붙임. 곡을 처음부터 다시 틀지 않음. 돌아올 때도 같게.
- 세션(층) = 베이스(= 전등 소리) · 전등 지지직(타악) · 킥 · 스네어 · 하이햇 · 건반/음률 · 패드 · 베이스 솔로 … 상태마다 켜고 끔(세로 쌓기) + 상태마다 다른 마디 묶음(가로 이어 붙이기).
- 전등 떨림 그림은 음악의 전등 칸을 따라감(소리와 빛이 같은 순간). 대기 화면 떨림은 지금처럼 드물게(브레이크 · 베이스 솔로 자리).
- 웹은 첫 누름 전엔 소리를 못 냄(브라우저 자동 재생 막음) → 처음 화면은 소리가 막혀 있으면 검은 화면에서 한 번 눌러 시작하게(앱 감싸기 = 안드로이드 WebView는 `setMediaPlaybackRequiresUserGesture(false)`로 바로).

- 식물 = 대기 화면의 그 의자 · 내 대표 식물(단계 그림 · 화분까지), 로그인 전이면 기본 식물.
- 누르기: 점화 전 = 건너뜀(다음 마디가 점화) · 단추가 뜬 뒤 = (로그인 상태) 어디든 눌러도 켜짐. 로그인 · 새로 시작하기 · 다시 시도 · 오프라인 체험 · 초대 링크(대결 방으로 — 켜짐 없이 셔터) · 가입 → 처음 식물 고르기는 예전 그대로 동작, 들어가는 순간(`enterGame`)만 켜짐으로.
- 소리가 막힌 브라우저 = 검정 + 아래 작은 '화면을 누르면 시작해요'(천천히 숨쉬듯) → 누르면 그때부터 조율. 막혀 있지 않으면(앱 WebView · 자동 재생 허락 — `sound.js tryAutoStart`, `navigator.getAutoplayPolicy`를 알려 주는 브라우저면 미리 묻고) 바로 시작.
- **디스플레이 켜짐**(`loftBoot`): 방을 덩어리로 나눠 저마다 생김새를 따라 LED(2×2칸)가 하나씩 — 바닥 = 의자에서 타원 고리로 퍼짐(바닥 타일 고리 그대로) → 벽 = 바닥 물결이 벽 밑에 닿는 대로 둘레를 따라 양옆으로 번지며 위로 타고 오름 → 천장 = 벽 윗단에서 전등 쪽으로 모임 → 창 테 = 아래에서 위로 고리를 따라 → 창(유리 디스플레이) = 가운데 가로 줄에서 위아래로 펼쳐지며 우주가 나타남(옛 화면 켜지듯). LED 하나는 켜지기 직전 푸른 불씨 → 하얗게 번쩍(칸마다 한 점이 더 밝은 점 무늬) → 원래 색. 의자는 디스플레이가 아님. 경계 = 그림을 격자 확대로 잰 곡선(천장 ↔ 벽 y = 87 − 0.00137(x−135)², 벽 ↔ 바닥 y = 338 + 0.000494(x−135)², 창 가운데 (134, 208) · 테 반지름 101). 켜짐이 끝나는 마디에 대기 화면으로('cut') — 대기 화면은 `from: 'boot'`면 식물을 다시 투영하지 않고 옆 창 · 글자만 0.6초에 걸쳐 나타남, 창 밖 풍경은 처음 화면이 고른 것 그대로.
- 처음 식물 고르기(`starter`)도 같은 꺼진 방 · 전등 아래 의자(바꿀 때마다 투영기가 비춤) → '시작'에 같은 켜짐.
- 로그아웃 = 처음 화면 곡으로(디스플레이 꺼지는 소리) → 조율부터 다시. 로그아웃 직후 대기 화면이 한 장 더 그려질 때 상태가 비어 오류가 나던 것도 막음(`home.draw`).

### 3. 새 곡 · 상태 넣는 법
- **상태**: `music.js STATES`에 `{ song, mix: { 층: 세기 배수(0 = 끔) }, pad, arp, tone(거름 Hz), wait }` → 장면을 `router.js SCENE_MUSIC`에(또는 장면 객체에 `music: '상태'`).
- **곡**: `SONGS`에 `{ swing, crkVis, brkVis, bar(곡 안 마디, 지금 상태, 상태 정의) → { L: { 층: 16칸 글자 }, ch, nx, base } }`. 글자 = 음(`D2`) · 화음(`C` 지금 · `N` 다음 · 이름) · `-` 이어감 · `.` 쉼, 꼬리 `^` 세게 · `_` 약하게 · `/` 아래에서 끌어올림. 북 = `X x o O r R`(강 · 보통 · 꾸밈 · 열린 하이햇 · 두 번 · 세 번). 전등 = `j J`(지직 · 지지직) · `W Q Z`(브레이크 — 그림이 온전히 떪) · `t`(소리만 찍).
- **층 → 악기 · 기본 세기** = `LAYER`, 버스 세기 · 울림 = `buildGraph`. 섞음은 `soundreel --stems`(층마다 RMS)로 맞춤.
- **장식** = `fillKind`(어디서 → 어디로) + `FILLS` + `FILL_MUTE`.

### 4. 확인 도구
- **영상(소리 포함)**: `node tools/shots/introvideo.mjs [--out intro_flow] [--tap 15.95] [--home 36] [--battle 13] [--after 9] [--png 초,…] [--crf PERC_LOSSLESS]` — 처음 화면 → 누름 → 켜짐 + 붐뱁(브레이크 포함) → 출전 · 매칭 → 전투(카드 두 번) → 다시 대기. 그림 = 앱 시각을 30장/초로 정확히 넘기며 실제 화면 그대로(`main.js __frame` — 누르기 · 단추 소리까지), 소리 = 같은 시각으로 기록한 음악 · 효과음 사건을 오프라인으로 구움(`sound.js rec`) → 블렌더로 H.264 + AAC(`video.mjs writeMP4Files` · `mp4_blender.py` 소리 띠). 장 PNG는 임시 폴더에(긴 영상도 메모리에 안 쌓임).
- **들어 보기(WAV)**: `node tools/shots/soundreel.mjs --out music_reel`(상태 차례 전부 — 처음 화면 → 대기 → 매칭 → 전투 → 승리 → 결과 → 대기 → 식물 관리 → … → 패배) · `--plan "0:title,13:boot,40:ready,44:battle,70:win"` · `--stems`(층 세기) · `--sfx all`(효과음 전부) · `--loud`(휴대폰으로 듣기 좋게 평균 −16dB, 0.8 넘는 꼭대기만 부드럽게 누름 — 영상 도구는 늘 이것).
- 처음 화면은 첫 장(검정)에서 전등 빛 층 · 꺼진 방 · 켜짐 순서를 미리 잼(`loft.js loftPrepare`) — 점화 · 켜짐 순간에 멈칫하지 않게.
- **정지 그림**: `?scene=title&at=12`(초) · `&bootu=0.5`(켜짐 중간) · `v2shots.mjs`의 `01_title` · `01_title_dark` · `01_title_boot`. 소리 막힘 길 = `?mute=1`(자동 시작 안 함).
- 콘솔: `__sound.conductor`(지금 상태 · 예약) · `__sound.lampNow()` · `__sound.introTime()`.

### 5. 아직 · 물을 것
- 곡은 사람 귀로 듣고 고르지 못함 — 코드 · 층 세기(RMS) · 스펙트로그램으로만 점검. 사용자가 영상을 들어 보고: 대기 곡 진행 · 가락 취향, 전투 곡 성격(어두운 트랩 + 칩 가락 — 예전 칩튠 전투곡보다 느린 90 BPM 반박자), 조율 길이(약 5초), 붐뱁 세기 · 먼지 정도.
- 누름 · 타격 같은 효과음은 박에 맞추지 않음(반응이 빨라야 해서) — 승패 가락 · 전등 소리만 박에 엮음.
- 휴대폰 실기 성능(노드 수 · 켜짐 2~3초 동안의 칸 계산)은 아직 실기로 재지 않음.
