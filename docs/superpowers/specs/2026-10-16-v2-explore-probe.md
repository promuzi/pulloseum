## 규칙(`v2/src/game/catalog.js` · `logic.js` — 서버 · 화면 공용)
- **탐사 1번 = 연료 캡슐 1 + 탐사비**(1궤도 40 · 2궤도 70 · 3궤도 110 · 4궤도 160). 캡슐 = 무료로 8시간에 1(최대 3) + 레벨업 상자(1, 5레벨마다 2) + 봇 판 승리 25% · 친구 대결 승리 50% + 보석 상점(3개 = 보석 5). 재배사 레벨 문턱(1 · 4 · 8 · 13)은 그대로(여유).
- **성공 확률** = 0.96 − 0.07×위험 − 0.012×짐×(1 + 0.5×위험) + 0.025×(내구성 − 1) − 0.3×(1 − 내구도 비율), 0.35~0.98. 짐 = (탐사 장치 − 1) + (채집기 − 1).
- **닳음** = 3 + 4×위험 + 1.5×짐×(1 + 0.3×위험), 성공이면 그 0.7~1.3배 · 실패면 2.2배. 내구도 0이면 못 나감 → 고치기(내구도 1당 돈 2, 모자라면 되는 만큼).
- **성공 보상**: 종자(종자형 92% · 섞임 70% · 자원형 35%, 어느 식물인지는 행성 표 그대로) + 채집기 단계만큼 보상 칸(1 + ⌊0.75×(단계 − 1) + 0~0.5⌋). 칸마다 돈(탐사비의 15~40% × 풍요) · 물 · 비료 · **부품**(자원형 2배 · 섞임 1.3배) · 접목 가지 · 회귀 주사 · 보석 — 탐사 장치가 높을수록 뒤 셋 쪽.
- **실패**: 탐사비의 15%만 건짐, 경험치 1/3.
- **개체값**: 종자에 `ivk` = 행성 생기(0~2) + ⌊(종자 보관함 − 1)/2⌋ → 심을 때 능력치마다 1 + ivk번 굴려 가장 좋은 값(상점 종자 = 한 번).
- **강화**: 단계 n → n+1 = 돈 150×n^1.5 · 부품 3n. 최대 = 연료 탱크 4 · 나머지 5. 내구성 강화 = 내구도 한도 +20(60 → 140) · 지금 값도 +20.

## 지역(2026-10-16 사용자 "행성 지도에서 지역 고르기 … 좋아 추천대로 고고")
- 행성마다 3~4곳(`catalog.js REGIONS` → `PLANETS[].regions`). **탐사 장치 단계로 하나씩 열림**(1 · 2 · 3 · 4) — 강화할 이유. 잠긴 곳도 눌러 미리 볼 수 있고 '탐사 장치 N단계가 필요해요' + 정비실(탐사 장치).
- **첫 곳 = 행성 값 그대로**(옛 판과 같은 확률 · 보상 — 지역 없이 보낸 요청 · 모르는 지역 id도 첫 곳). 규칙 `logic.js regionOf(pl, id)` = 행성 값에 지역 값을 얹음 · `explore(s, 행성, rng, now, 지역)` · `exploreOdds(s, 행성, 지역)`(+ `gem` = 보상 칸 하나가 귀한 것일 확률) · 결과에 `region` · `area`. 화면 요청 `act('explore', { planet, region })`.
- 지역 값: `pool` = 그 행성 식물 중 일부(흔한 것을 겹쳐 쓰면 더 자주) · `dh` 위험 ± · `dv` 생기 + · `kind` 종자형/섞임/자원형 · `rare` = 귀한 보상 배수(희귀 종자 18% · 접목 가지 · 회귀 주사 · 보석 무게에 곱함 — 위험 −1 = 0.8 · 0 = 1 · +1 = 1.3 · +2 = 1.6) · `mut` = 변이 종자 확률 배수(1 · 1.5 · 2 — `explore`의 `seedOf(…, { mut: Z.mut })`로 넘기는 일은 변이 작업에서). 수치는 가볍게, 밸런스는 나중에(사용자).
