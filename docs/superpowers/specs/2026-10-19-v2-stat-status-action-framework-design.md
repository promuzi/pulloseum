# 능력치 강화 · 상태이상 · 행동 효과 재분류 (2026-10-19, 5차)

능력치 독립 강화와 상태/준비/행동을 처음 나눴던 5차 검토 기록이다. **최신 대분류·기타 편입·지속/해제 표는 [효과 분류 통합표](2026-10-19-v2-effect-taxonomy-table-design.md)**를 따른다. 순수 능력치 감소는 디버프로 사용자 분류, 의지/면역은 이로운 상태의 비체력 영역, 방어구는 **갑주**로 바꿔 스킬에 둔다. 아래 당시의 보류/분류가 최신을 덮지 않으며 겹별 독립 만료/교체 보존과 만개 원안 확인은 보존한다. [이전 4차](2026-10-19-v2-effect-lifecycle-design.md)도 보존 기록이다. 게임 코드/배포는 변경하지 않는다.

> **은신 후속 결정:** [은신 통합·회피 후 추가 공격](2026-10-19-v2-unified-stealth-design.md). 분신은 별도 상태로 두지 않고 은신 연출로 통합한다. 쏜위드의 기습/그림자 분신 계열의 연타는 상대 공격을 피한 직후 추가 공격하며, 선후공에 따른 대기·소비 흐름을 동문서에 정리한다.

## 1. 이번 사용자 방향

- 버프 종류를 **체력을 제외한 능력치 종류에 대응**시킨다. 방어력/공격력/기동성/치명 확률/정확도 증가 등을 둔다.
- 능력치 강화는 오래 유지하거나 기간이 없고 계속 중첩할 수 있다. 교체로 사라지지 않는다. **각 겹은 자기 남은 기간으로 따로 만료**한다. 기존 겹을 갱신하는 방식과 다르다.
- 상태이상은 해로운 것과 이로운 것으로 나눠 같은 상태이상 체계로 다룬다. 지속 회복은 **재생 상태**다.
- 은신/보호막/반사/집중 등 준비·보호 효과는 버프도 상태이상도 아니다. **해당 조건/사용/소모가 없으면 시간만으로 사라지지 않는다.** 분신은 후속 결정에 따라 은신 연출로 통합한다.
- 정화는 회복/회피/방어처럼 실행하는 기술이다. 방어구도 보호량을 제공하는 회복의 다른 형태로 취급하며 버프/디버프 만료에 얹지 않는다.
- 만개를 확인하고, 새 틀에 들어가지 않는 효과를 우선 별도로 빼 검토한다.

따라서 직전의 **일시 버프 2턴 통일/동일 효과는 기간 갱신/준비형도 버프 제거로 삭제**를 이 새 틀의 기본값으로 유지하지 않는다. 준비·보호 효과의 교체 시 처리도 이전 버프 분류만을 근거로 자동 결정하지 않는다.

## 2. 새 틀에 분명히 들어가는 것

| 영역 | 들어가는 효과/기술 | 처리 방향 |
|---|---|---|
| 능력치 강화 | 공격력/방어력/기동성/치명 확률/정확도 증가 | 능력치별 강화 목록. 겹마다 효과량/기간을 보관하고 교체에도 남김 |
| 해로운 상태이상 | 화상/독/출혈, 젖음/빙결/감전/기절/덩굴/교체 금지/도발/포자/햇빛 방해 등 | 상대를 해치거나 행동을 방해하는 상태. 세부 피해/겹/발동 조건은 효과별로 정함 |
| 이로운 상태이상 | 재생 | 기간 동안 턴 끝 회복. 즉시 체력 회복과 구별 |
| 준비·보호 효과 | 집중/은신(분신 연출 포함)/반사/보호막/방어구/불타는 의지 | 시간 대신 정해진 사용 횟수·깨짐 조건·남은 보호량으로 다룸. 버프/상태이상 목록에 중복 등록하지 않음 |
| 실행하는 행동 | 공격/즉시 회복/정화/방어/회피/광합성/전환 등 | 실행 시 효과를 처리. 기술 하나가 여러 종류의 결과를 만들 수 있음 |

**'해로운 상태'에는 체력 피해뿐 아니라 기절·기술 봉인 같은 방해도 포함**하는 해석을 추천한다. 이것은 사용자 표현 '피해'를 넓게 해석한 배치다. 체력 피해만 뜻한다면 해당 제어 효과는 별도 보류 대상이 된다. 유해/이로움은 효과를 받는 대상 기준으로 판단한다. 자해 화상은 시전자가 자신이어도 유해, 상대에게 준 회복은 받는 상대에게 이롭다.

젖음/빙결처럼 방해와 능력치 변화를 함께 갖는 복합 상태는 일단 해당 상태 하나로 보존한다. 이번에 그 부가 감소를 별도 약화 겹으로 자동 분해해 정화 개수나 타이드 피날레 종류 수를 바꾸지 않는다. 순수 능력치 감소의 분류는 아래 보류 목록에서 다룬다.

회피율/치명 피해율/관통률 등을 추가 능력치로 등록할지는 미결이다. 이름에 숫자가 들어간다고 전부 새로운 버프 종류로 추가하지 않는다. 최대 체력 증가 카드도 이번 '체력 제외' 원칙 때문에 전투 중 강화 겹으로 자동 변환하지 않는다.

## 3. 능력치 강화의 독립 만료

사용자 예의 공격력 강화 4턴/2턴/3턴을 이미 보유한 시점부터 세면 다음과 같다. 이 표는 신규 부여 턴을 언제 세는지와 별개로 **주어진 남은 기간을 정산하는 예**다.

| 정산 시점 | 살아 있는 겹의 남은 기간 | 공격력 강화 겹 수 |
|---|---|---:|
| 현재 | 4 / 2 / 3 | 3 |
| 턴 끝 1회 뒤 | 3 / 1 / 2 | 3 |
| 턴 끝 2회 뒤 | 2 / 1 | 2 |
| 턴 끝 3회 뒤 | 1 | 1 |
| 턴 끝 4회 뒤 | 없음 | 0 |

새 강화는 새 겹을 추가하고, 기존 겹의 기간을 늘리거나 모두 같은 만료 시점으로 덮지 않는다. 무기한 겹을 허용하면 그 겹은 시간 정산으로 사라지지 않는다. **중첩 가능이라는 방향과 수치/겹 상한을 무제한으로 확정하는 것은 구별**하며 상한은 아직 정하지 않았다.

교체 중에도 전투 턴에 따라 유한 겹의 시간을 진행하는 것을 추천한다. 교체 때 일괄 제거하거나 시간을 얼리는 규칙은 넣지 않는 안이다. 같은 능력치 겹의 효과량은 합산하는 방향을 추천하되, 고정 수치/비율/최대치와 겹당 증가량은 따로 정해야 한다. 기존 분노 +25%를 그대로 무기한 반복 누적하는 수치까지 확정한 것은 아니다.

기동/공격 강화 등 이름은 능력치에 대응시키고, 분노/가속은 그 강화를 주는 기술 이름으로 남길 수 있다. **집중의 다음 공격 한 번 치명 보너스는 준비 효과**, 지속 치명 확률 강화는 능력치 강화로 구별한다.

## 4. 준비·보호 효과에서 정해진 것과 남은 것

| 효과 | 이번 틀로 설명 가능한 부분 | 아직 정하지 않을 조건 |
|---|---|---|
| 보호막/방어구 | 남은 보호량을 제공. 공격받지 않으면 시간 만료 없이 남음 | 재사용 시 복구/합산/상한, 교체 후 유지, 전용 파괴/해제 범위 |
| 집중 | 해당 공격을 실행할 때 보너스를 소비. 공격하지 않으면 남음 | 연타 적용 범위와 다른 치명 준비와의 공존을 새 공통 규칙으로 최종 정리 |
| 불타는 의지 | 다음 검방술 2회 속성 부여라는 기존 기술을 횟수형 준비로 표현 가능 | 재부여/교체/전용 해제 규칙. 기존 2회를 이번 분류만으로 1회로 줄이지 않음 |
| 은신(분신 연출 포함) | 실제 사용 이후 회피하면 연결된 기습/연타를 즉시 실행. 선후공별 흐름은 [후속 설계](2026-10-19-v2-unified-stealth-design.md) | 공통 회피율/해제 조건/교체/재사용/연타 중 피격 처리 |
| 반사 | 맞았을 때 반응하며 안 맞으면 보관 가능 | 한 타에 소모할지/공격 행동 전체에 적용할지/반사량 예산을 둘지 |

여기서 '1회성'을 모든 효과가 무조건 첫 타 하나에 사라진다는 뜻으로 확정하지 않는다. 보호막은 남은 보호량, 속성 부여는 사용 횟수 등 필요한 소모 단위가 다르다. 사용자 결정은 **사용/소모 조건 없이 시간만으로 없어지지 않는 방향**이며, 위 남은 조건을 조용히 대신 결정하지 않는다.

보호막/방어구에는 남은 보호량을 관리하면 되고 강화 겹/버프 만료를 추가하지 않는다. 재생은 이로운 상태, 즉시 회복은 실행 행동, 보호량 부여는 준비·보호라는 서로 다른 처리를 갖는다. 내부적으로 남은 양/횟수를 저장해야 하는 것과 플레이어 규칙에서 상태이상으로 분류하는 것은 별개다.

## 5. 만개 확인 — 독립 상태를 줄일 수 있음

만개는 임의로 덧붙인 이름이 아니라 **사용자의 페탈로즈 원안 기술**이다. [종 기술표 §1](2026-10-18-v2-species-skills.md)에 원문 '만개: 자신의 모든 스탯이 증가함'이 있다. 직전 확정 수치는 공격/방어/기동 +5%씩/최대 4겹/판 끝까지/햇빛 2였다.

새 틀에서는 **독립된 만개 상태를 두지 않아도 된다.** 기술을 쓰면 공격력 강화·방어력 강화·기동성 강화 각각에 새 겹을 주는 식으로 표현할 수 있다. 따라서 **만개라는 별도 상태/그 상태 전용 중첩 처리를 없애고 공통 강화로 표현**하는 안을 추천한다.

**스킬 자체 삭제와 독립 상태 삭제를 구별한다.** 이번에는 원안 스킬을 지우지 않고 재표현 후보로 보존한다. 기존 +5%/4겹 상한도 새 공통 강화량·상한을 정할 때 함께 재검토한다. 만개를 단순히 삭제하면 페탈로즈의 성장 기술 하나가 없어지므로 사용자 원안을 확인하지 않은 채 기술 목록에서 빼지 않는다. 정확도/치명 강화까지 자동 추가하지도 않는다.

윈드페탈 칼춤의 적중당 공격 +5%/최대 +30%도 독립 '칼춤 버프' 대신 공격력 강화 겹으로 표현할 수 있다. 기존 적중당 부여/상한은 공통 겹 규칙과 맞추기 전까지 보존한다.

## 6. 틀 밖으로 별도 추출할 목록

아래는 삭제 목록이 아니라 **새 영역에 자동으로 넣지 않고 남겨둘 검토 목록**이다. 현재 공통 효과/공통 장치/설계 받은 1~9번을 대조했으며, 아직 사용자가 설계하지 않은 10~46번의 모든 옛 초안을 확정 재분류한 것은 아니다.

| 별도 보류 묶음 | 실제 항목 | 바로 넣기 어려운 이유/다음 결정 |
|---|---|---|
| 환경 | 강풍/지옥전개, 기존 비/바람길/눈보라 | 식물이 아닌 지도에 남는 원천. 환경 영역을 따로 유지할지 확인. 앞의 환경 횟수 결정은 보존 |
| 설치물/독립 개체 | 가이아 성체·희생체/쏜위드 덫 | 소유자/진영/체력/유지비/철거/공유 발동이 필요. 단순 버프나 개인 준비로 환원 불가 |
| 고유 자원/모드 | 스파크 전기/앰버 허세·위축/모드 전환 | 보유량·상반된 바·소비에 따라 여러 결과를 만듦. 해제 가능한 일반 상태와 다름 |
| 전투 제한/기록 | 충전 정지/기술 사용 횟수/일반 교체의 재사용 대기시간/연속 기절 방지 버팀/선공·명중 불운 보정 | 기술·전투 운영 규칙. 적이 거는 교체 금지 상태와 구별. 정화로 위험/사용 횟수를 초기화하면 기존 설계가 달라짐 |
| 순수 능력치 감소 | 약화의 공격 감소/부식의 방어 감소/교란의 정확도·기동 감소 | 능력치 강화의 음수 겹으로 대칭 처리할지, 해로운 상태로 둘지 미정. 교체·중첩·정화 정책도 함께 달라짐 |
| 능력치 목록 밖 배율 | 일시 철벽의 직접 피해 감소/치명 피해율·관통률 등 | 방어력 증가와 수식이 다름. 새 기본 능력치로 등록하거나 기존 능력치/행동 성질로 환원할지 결정 필요 |
| 예방/면역 | 옛 정화 보호/속성·카드 면역 | 정화의 즉시 해제와 별개. 정화에 자동으로 보호를 붙이지 않는 안을 추천하며, 보호 자체를 남길지는 보류. 타고난 면역은 부여 상태가 아닌 상시 규칙 |
| 시한·예약·당해 턴 반응 | 쏜위드의 다음 차례 기습/지연 폭발/메아리/죽은 줄 알았나?/그 턴 방어·회피 반응 | 정해진 시각/그 턴에 작동하는 기존 기술. 사용하지 않으면 계속 보관하는 준비와 일괄 통합하면 시점·실패 위험이 달라짐 |
| 복합/연결/조건 판정 | 지속 씨앗 흡수/지옥의 주민 판정/갈망·불씨의 화상 연동 | 한쪽의 피해와 다른 쪽의 회복, 또는 대면/화상 조건을 참조. 본체 상태와 연결 종료 조건/계수는 따로 정리해야 함 |
| 상시 패시브/기초 보정 | 카드의 상시 반사·재생/체력 조건 공격 증가/최대 체력 증가 등 | 매번 강화 겹을 부여하는 기술이 아님. 장착/조건부 계산을 강화 무한 누적으로 바꾸지 않음 |
| 제거·복사·소비의 대상 범위 | 정화/치유의 물/윤회/청산/업화/조화/훔치기 | 행동으로는 틀 안에 들어가지만 기존 '버프/디버프 전체' 필터가 새 분류와 맞지 않음. 강화 겹/이로운 상태/해로운 상태/준비·보호 중 어떤 것을 만질지 다시 정의 |

가이아 성체의 방어/공격/기동 상승은 특히 **원천이 존재하는 동안의 계산값**으로 남기는 안을 추천한다. 턴마다 영구 강화 겹을 쌓으면 주인 교체 시 성체가 사라진다는 앞의 결정과 어긋난다. 환경/패시브가 주는 상승도 자동으로 누적 강화로 바꾸지 않는다.

덫은 조건부로 소비되는 준비와 유사하지만 진영 공유/설치자별 소유/별도 폭발이 있어 일단 보류한다. 소유 범위와 소비 규칙을 맞추면 준비 영역으로 편입할 가능성도 열어 두며, 모든 설치물이 반드시 새 분류로 영구 분리되어야 한다고 확정하지 않는다.

기술의 광역/확정 명중/확정 치명/단발 관통/즉시 흡수 회복은 **해당 행동의 성질/처리**로 설명할 수 있어 새 상태 종류를 만들 필요가 없다. 지속 흡수 상태의 연결 문제와 즉시 흡수 공격을 구별한다.

## 7. 포함 가능하지만 상호작용을 다시 정해야 하는 것

- **정화:** 실행 행동으로 분류. 앞의 기본 2종/전문 전체는 제거 수 결정으로 보존하되 새 틀의 어떤 유해 효과를 한 종류로 세는지 다시 명시해야 한다. 양수 강화 겹이나 보호막을 옛 버프 목록에 있었다는 이유로 지우지 않는다.
- **윤회/조화/청산/업화:** 이전 문구의 '버프/디버프'가 가리킬 새 대상을 다시 적는다. 특히 준비·보호가 그 둘 밖으로 나갔으므로 기존 제거/복사 범위가 그대로라고 가정하지 않는다. 화상 제외/종류별 피해 등 기존 결정도 보존한 채 새 범위를 논의한다.
- **재생/자가 화상/얼음:** 유익·유해는 대상에게 미치는 전체 효과로 구별하는 안. 얼음의 피해 감소 같은 부가 이득이 있다고 별도 이로운 상태를 자동으로 추가하지 않는다.
- **교체:** 능력치 강화 보존은 사용자 결정. 상태이상/준비·보호/예약 공격까지 같은 보존 또는 삭제를 자동 확대하지 않는다. 지속 상처 대기석 피해 등 앞의 미결도 이번에 확정하지 않는다.

## 8. 기록 범위

이번 결과는 새 틀의 확정 방향, 자연스럽게 들어가는 효과, 틀 밖 보류 묶음의 목록이다. 별도 설계 검토에서 독립 만료 예/사용자 핵심 구분/만개의 스킬·상태 구별을 확인했고 중요한 누락은 발견하지 않았다. 종 원안/스킬 이름은 보존하고 만개의 독립 상태를 줄이는 안만 제시한다. 겹당 수치/상한/기간/제거·복사 범위/준비 소모 단위를 이번 분류만으로 확정하지 않는다. 코드 연결/새 전투 저장 형식/균형 검증/배포는 아직 진행하지 않는다.
