# v2 변이 상성 — 안과 비교(2026-10-17, 결정 대기)

> 상태: **㉮ 변이끼리 다섯 바퀴 = 사용자 허락("가는 허락")**. ㉯(변이 ↔ 속성)는 사용자 "하나씩 말고 이기고 지는 걸 적절하게 한 개 이상으로 — 다시 비교해 볼게" → 새 안(v2) 비교 중. 가상 새 종류(금속 · 요정 · 마법 속성 + 기계 변이)는 사용자 "나중에 넣게 되면 밸런스가 맞을 수 있으니 임의로 가상으로 넣어서 맞춰 보자" → 표만 보관(게임엔 아직 안 넣음).
> 배율: 속성 상성 ×1.5(지금 · `battle/model.js elemMult` — 약점만, 반감 없음), 변이 상성 ×1.25(속성이 먼저 · 변이는 양념). 셈 도구 = scratchpad `matchup_tally.mjs`(속성 · 변이마다 이기는 수 − 지는 수).

## ㉮ 변이끼리(허락) — 다섯 바퀴, 앞이 뒤를 이김
무기 → 포식 → 포자 → 독성 → 용족 → 무기: 칼이 턱을 벰 · 버섯을 먹어 치움 · 균이 독을 삭임 · 독은 큰 짐승을 쓰러뜨림 · 비늘이 칼을 튕기고 숨결이 쇠를 녹임. (적용 범위 — 변이 기술(카드)로 칠 때만 / 변이 식물의 모든 공격 — 결정 대기)

## ㉯ 변이 ↔ 속성
| 변이 | 처음 안 v1 약함 / 셈 | 새 안 v2 약함(이 속성에 맞으면 ×1.25) | 새 안 v2 셈(이 속성을 치면 ×1.25) |
|---|---|---|---|
| 무기 | 번개 / 풀 | 번개(쇠에 전기) · 물(녹이 슮) | 풀(벰) · 빙결(쇠망치로 깸) |
| 포식 | 빙결 / 물 | 풀(덩굴이 턱을 묶음) · 빙결(얼면 못 삼킴) | 물(물고기 잡듯) · 바람(날벌레 잡듯) |
| 독성 | 물 / 풀 | 물(묽어짐) · 풀(약초가 해독) | 대지(흙을 썩힘) · 빙결(부동액처럼 얼음을 녹임) |
| 포자 | 불 / 대지 | 불(타 버림) · 바람(흩날림) | 대지(흙을 삭힘) |
| 용족 | 빙결 / 불 | 빙결(추위) · 바람(돌풍에 날개가 꺾임) | 불(불을 먹음) · 번개(천둥을 부림) |

### 속성마다 이기는 수 − 지는 수(지금 속성표 + 변이표)
| 속성 | 속성표만(지금) | + v1 | + v2 |
|---|---|---|---|
| 불 | +1 | +1 | +1 |
| 물 | −1 | −1 | 0 |
| 풀 | −1 | −3 | 0 |
| 대지 | +2 | +1 | 0 |
| 바람 | −1 | −1 | 0 |
| 번개 | 0 | +1 | 0 |
| 빙결 | 0 | +2 | 0 |
- 변이 쪽(v2 + ㉮): 무기 · 포식 · 독성 · 용족 0, 포자 −1(버섯만 · 피어나기가 세서 둠 — 금속을 넣는 날 '포자 > 금속'으로 0).

## 가상 새 종류(표만 보관) — 금속 · 요정 · 마법 속성 + 기계 변이
### 속성표에 더하기(지금 관계는 그대로)
불 > 금속(녹임) · 물 > 금속(녹슮) · 금속 > 빙결(깸) · 금속 > 요정(차가운 쇠 — 옛이야기) · 바람 > 요정(날아감) · 빙결 > 요정(날개가 얼음) · 요정 > 대지(메마른 땅을 꽃밭으로) · 요정 > 마법(장난으로 주문을 흐트러뜨림) · 요정 > 불(이슬로 불씨를 끔) · 마법 > 대지(염력으로 바위를 띄움) · 마법 > 불(마법 방패가 불길을 되돌림) · 풀 > 마법(들풀 향이 홀림을 풂)
→ 열 속성 모두 0(지금 센 대지 · 약한 물 · 풀 · 바람도 0이 됨).
### 변이 ㉮ = 여섯 바퀴
무기 → 포식 → 포자 → 독성 → 용족 → **기계** → 무기(지금 '용족 > 무기'가 '용족 > 기계 > 무기'로: 숨결이 기계를 녹임 · 기계가 무기를 앞지름).
### 변이 ↔ 속성에 더하기
기계 > 물(펌프) · 기계 > 풀(예초기) · 기계 > 바람(풍차) · 대지 > 기계(흙모래가 톱니에 낌) · 마법 > 기계(주문이 기계를 고장 냄) · 요정 > 기계(요정 장난 — 그렘린) · 요정 > 용족(자장가로 잠재움) · 독성 > 요정(독에 약함) · 무기 > 요정(날개를 벰) · 마법 > 독성(정화 주문) · 용족 > 마법(용은 마법에 강함) · 무기 > 마법(주문보다 칼이 빠름) · 금속 > 무기(쇠 방패가 칼을 막음) · 포자 > 금속(곰팡이가 쇠를 갉아 먹음) · 대지 > 무기(돌에 날이 무뎌짐 — 새 속성이 들어와 대지가 약해지는 만큼 되돌림)
→ 속성 열 · 변이 여섯 모두 이기는 수 = 지는 수(모순 0).

## 정할 것
1. ㉯ = 새 안 v2로 할지(위 비교).
2. ㉮ 적용 범위: 변이 기술(카드)로 칠 때만 / 변이 식물의 모든 공격.
3. 배율 ×1.25 그대로.
4. 가상 확장 표는 지금처럼 보관만(새 종류를 넣는 날 그대로).
