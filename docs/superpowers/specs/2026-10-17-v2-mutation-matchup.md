# v2 변이 상성 — 안과 비교(2026-10-17, 안 3 · 게임엔 아직 안 넣음)

> 흐름: ㉮ 변이끼리 다섯 바퀴 = 사용자 허락("가는 허락") → ㉯(변이 ↔ 속성) 사용자 "하나씩 말고 이기고 지는 걸 적절하게 한 개 이상으로" → 안 2 →
> 사용자 "무기는 무기 종류에 상성을 다르게 — 그게 무기 변이의 재미" · "총은 바람에 약한 걸로(명중 못 시킴)" · "화염방사도 넣자" · "무기류는 다 물에 약한 게 — 물을 공격할 수가 없잖아, 다만 번개 속성 무기는 다른 걸로" ·
> "포식 > 바람 빼자" · "용이 바람에 약한 거 빼자" · "요정이 불에 강한 거 빼자" · "마법은 변이로 · 풀 > 마법 빼고 · 마법은 속성 상성에서 빼 변이에 넣어서 조정" · "나머지는 네 추천대로" → **안 3(아래)**.
> 같은 때 사용자 "용을 속성으로 넣는 건 어때? 의견만" → 의견 = 지금은 변이로 둠(아래 끝).
> 배율: 속성 ×1.5(지금 · `battle/model.js elemMult` — 약점만), 변이 상성 ×1.25 · 무기 '안 듦' ×0.8(새 규칙). 셈 = scratchpad `matchup_search.mjs`(속성 · 변이마다 이기는 수 − 지는 수 · 가상 확장은 고르게 되는 조합을 찾음).

## ㉮ 변이끼리(허락) — 다섯 바퀴, 앞이 뒤를 이김(×1.25)
무기 → 포식 → 포자 → 독성 → 용족 → 무기: 칼이 턱을 벰 · 버섯을 먹어 치움 · 균이 독을 삭임 · 독은 큰 짐승을 쓰러뜨림 · 비늘이 칼을 튕기고 숨결이 쇠를 녹임.
- 적용(추천): 치는 쪽 = 변이 기술(카드 · 그 변이 개성 기술)로 칠 때 · 맞는 쪽 약함 = 늘.

## ㉯ 변이 ↔ 속성(안 3)
| 변이 | 약함(이 속성에 맞으면 ×1.25) | 셈(이 속성을 치면 ×1.25) |
|---|---|---|
| 무기 | 번개(쇠에 전기) · 물(녹이 슮) | 무기 종류마다(아래) |
| 포식 | 풀(덩굴이 턱을 묶음) | 물(물고기 잡듯) |
| 독성 | 물(묽어짐) · 풀(약초가 해독) | 대지(흙을 썩힘) · 빙결(부동액처럼 얼음을 녹임) |
| 포자 | 불(타 버림) · 바람(흩날림) | 대지(흙을 삭힘) |
| 용족 | 빙결(추위) | 불(불을 먹음) · 번개(천둥을 부림) |
- 안 2에서 바뀐 것: 포식 > 바람 · 바람 > 용족 뺌(사용자), **빙결 > 포식도 뺌**(포식이 이기는 것 하나 · 지는 것 하나로 맞춤 — 추천).

### 무기 종류(칠 때 · 무기 기술마다)
| 무기 종류 | 지금 기술 | 셈(×1.25) | 안 듦(×0.8) |
|---|---|---|---|
| 칼(베기) | 칼날 베기 · 달군 칼날(불) · 블레이드바인 베기 기술 | 풀(덩굴 · 잎을 벰) | 대지(돌에 날이 무뎌짐) · 물(물은 벨 수 없음) |
| 망치(내려치기) | 쇠망치 내려치기 | 빙결(얼음을 깸) · 대지(바위를 부숨) | 물(쳐도 갈라졌다 다시 붙음) |
| 총(쏘기) | 가시 탄환 | 불(불길에 다가가지 않고 멀리서 쏨) | 바람(바람에 빗나감) · 물(물속에선 탄환이 느려짐) |
| 화염방사(새) | 화염 방사(새 무기 카드 — 불 · 멀리 · 여럿 · 화상) | 빙결(얼음을 녹임) | 바람(불길이 되돌아옴) · 물(불이 꺼짐) |
| 창(번개) | 번개 창(번개) | 물(전기 작살) | 풀(덤불에 창끝이 걸림) |
- 번개 무기는 물에 안 듦이 없음(사용자 "번개 속성의 무기는 다른 걸로"). 속성 배율과 곱함(달군 칼날 → 풀 = 불 1.5 × 칼 1.25).

### 속성마다 이기는 수 − 지는 수(지금 속성표 + ㉯ 안 3, 무기 종류 빼고)
불 +1 · 물 0 · 풀 +1 · 대지 0 · 바람 0 · 번개 0 · 빙결 0 / 변이: 포식 0 · 독성 0 · 포자 −1 · 용족 +1(무기는 칠 때 무기 종류로).
- 무기 종류까지 넣으면 물이 무기의 천적(대부분 안 듦), 빙결은 망치 · 화염방사에 약함 — 무기 식물은 상대 속성을 보고 카드를 고르는 재미.

## 가상 확장(표만 보관) — 금속 · 요정 = 속성, 기계 · 마법 = 변이
- 속성표에 더함: 불 > 금속(녹임) · 금속 > 빙결(깸) · 바람 > 요정(날아감) · 빙결 > 요정(서리가 날개를 얼림) · 요정 > 대지(메마른 땅을 꽃밭으로).
- ㉮ = 일곱 바퀴: 무기 → 포식 → 포자 → 독성 → 용족 → **마법** → **기계** → 무기(용은 마법에 강함 · 주문이 기계를 고장 냄 · 기계가 무기를 앞지름 — 지금 '용족 > 무기'가 이 셋으로 바뀜).
- ㉯에 더함: 기계 > 풀(예초기) · 기계 > 바람(풍차) · 번개 > 기계(합선) · 대지 > 기계(흙모래가 톱니에 낌) · 마법 > 불(마법 방패가 불길을 되돌림) · 마법 > 번개(주문으로 번개를 부림) · 요정 > 마법(장난이 주문을 흐트러뜨림) · 금속 > 마법(차가운 쇠가 마법을 끊음) · 포자 > 금속(곰팡이가 쇠를 갉아 먹음).
- 결과: 속성 아홉 = 불 +1 · 나머지 0, 변이 일곱 = 용족 +1 · 나머지 0(무기는 무기 종류), 모순 0. 새 넷 모두 이기는 것 · 지는 것 둘씩.

## 용을 속성으로? — 의견(사용자 "잠깐 고려만, 의견만")
지금은 **변이로 둠** 추천: ① 지금 용들은 이미 속성이 있음(드레이크캑터 불 · 프로스트드레이크 빙결 · 새로 올 현무캡 물) — 한 식물 = 속성 하나 구조에서 용을 속성으로 바꾸면 불 숨결 · 화상 같은 정체가 빠짐(둘 다 가지려면 이중 속성 = 사용자 '나중에') ② 변이면 어떤 속성에도 용을 붙일 수 있고(불 용 · 얼음 용 · 물 용), 용 카드 · 태생 용족 구조가 그대로 ③ ㉯ 표가 이미 용에게 속성 같은 상성(빙결에 약함 · 불 · 번개에 셈, ㉮ 독성에 약함 · 무기에 셈)을 줌. 이중 속성을 넣는 날 '용'을 두 번째 속성으로 쓰는 안을 다시 볼 만함.

2. 용 = 변이 그대로(의견) 동의 여부.
