## 최신 규칙과 이름

- **2026-10-20 사용자 후속 결정:** ‘덩쿨’(기존 표기 덩굴)을 **‘봉인’**으로 바꾸고, 기존 별도 봉인(직전에 사용한 기술을 2턴 제한)은 **폐기**한다. 남는 봉인은 사용 가능한 기술 하나를 무작위로 1턴 제한한다. 기존 봉인 사용 스킬의 대체 효과와 불속성 해제 여부는 미정. 이번 후속 결정은 문서에 반영했으며 바탕화면 엑셀은 열려 있어 덮어쓰지 않았다. 아래 표의 봉인은 이 새 이름을 뜻한다.
- **디버프는 능력치 약화만** 가리킨다. 정화로 제거하지 못하며, 같은 능력치를 올리는 자기 강화로 수치를 보완한다. 상태이상과 디버프를 다시 하나의 정화 대상으로 묶지 않는다.
- 버프·디버프는 기존 확정대로 **각 겹 5턴/독립 만료/교체 보존·시간 진행**이다. 수치 보완을 음수 겹 삭제나 잔여 기간 갱신으로 확대하지 않는다. 강화·약화의 구체적인 합산 공식과 상한은 별도 미결이다.
- **감전은 해로운 상태이상 → 데미지**에 포함한다. 약한 피해와 기존 확률형 마비를 함께 가진다. 피해량·피해 시점은 이번에 정하지 않았다. 행동 취소/면역 범위는 검토 대기 시트에 유지한다.
- 사용자 변경 이름을 그대로 채택한다: 치명 확률 증가 **예리함 → 치명**, 정확도 증가 **정밀함 → 집중**, 교체 금지 **→ 속박**. 기존 준비 효과의 집중도 사용자가 유지했으므로 임의로 이름을 바꾸지 않는다. 두 집중은 능력치 버프/1회성 준비라는 분류로 구별하고 이름 중복은 후속 검토할 수 있다.
- 다른 정화 대상·무작위 제거 수·개인 환경·준비 효과·교체 규칙을 이번 요청으로 새로 바꾸지 않는다.

## 원본 보존과 남은 문구

요청에 따라 감전 설명·소분류 병합 및 기간 관련 **27셀/병합 2범위**만 수정했다. 사용자 변경 이름·정화 불가 표기·빈 분류 셀·서식·행 높이·열 너비·확대율·스크롤·선택·틀 고정·드롭다운을 보존했다. 나머지 3시트는 내부 파일 바이트까지 그대로다.

사용자가 나머지 유지를 요청했으므로 다음 옛 문구도 자동 수정하지 않았다. **최신 판단에는 위 규칙을 우선한다.**

- 스킬 분류의 정화 설명에 남은 '디버프 제거'는 능력치 약화를 포함하지 않는 것으로 정정 기록한다. '정화의 겹별 제거' 검토도 순수 능력치 약화의 제거 여부를 다시 여는 뜻이 아니다.
- 사용자 변경명 치명·집중 옆의 기존 '명칭 제안' 비고는 편집 범위 밖이라 남겼지만, 이 두 이름은 이제 사용자 변경명이다.
- 감전 피해량·의지 기간, 대기석의 실제 발동/연결, 보호막 연타 범위 등 아직 정하지 않은 값은 만들지 않았다.

기존 전체 작성기를 다시 실행하면 사용자 편집을 덮으므로 사용하지 않는다. [부분 편집기](../../../tools/design/effect-taxonomy-20261019/edit-desktop.mjs)로 기존 파일을 가져와 작성하고 [원본 보존 검증기](../../../tools/design/effect-taxonomy-20261019/verify-desktop.py)로 허용 셀·병합만 옮겨 검사했다. Artifact Tool의 저장 과정이 화면 설정과 빈 행을 바꾸는 것을 확인해 원래 패키지의 나머지 부분을 유지했다. 실제 Excel 읽기 전용 출력에서도 감전 분류·기간·줄바꿈을 확인했다.
