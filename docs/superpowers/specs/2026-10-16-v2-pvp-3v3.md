# 3:3 친구 대결(교체전 PvP) 설계 — 2026-10-16

사용자 "남은 거 다해줘"(목록 중 '3:3 친구 대결'). 지금 친구 대결은 1:1만(`server/rooms.mjs`). 봇 3:3 교체전(`v2/src/battle/team.js` · 화면 `battle.js` swap3)과 같은 규칙으로, 두 사람이 수를 고르고 쓰러진 자리도 저마다 직접 채운다.

## 규칙
- 방장이 방에서 고름: **1:1 · 3:3 교체전**(기본 1:1). 바꾸면 둘 다 준비가 풀림. 대결 중엔 못 바꿈.
- 3:3 팀 = 그 사람의 저장된 3:3 팀(`s.team`, 홈에서 고르는 그 팀 — `setTeam` 일). 없거나 모자라면 스마트팜 앞에서부터 셋. 식물이 셋 안 되면 3:3 준비 불가("식물이 셋 있어야 해요").
- 방에서 팀을 바꾸면 `setTeam`으로 저장까지(팀 정의는 하나 — 봇 3:3과 같은 팀).
- 서로의 팀은 대결 전에 안 보임(1:1과 같음 — 사용자 "서로의 패는 보여주지 말자"). 대결 중에도 **상대 대기석은 나온 적 있는 식물만** 서버가 보냄(안 나온 식물 = 자리만: 살아 있음/쓰러짐). 상대 기술은 그 식물이 쓴 것 + 기본기만, 능력치 없음(1:1과 같음).
- 한 턴 = 두 사람이 기술 · 교체 · (쉬는 차례면) 쉬기 중 하나. 교체가 먼저(포켓몬처럼, 봇 3:3과 같음).
- **시간 초과 = 넘어감**(1:1과 같음 — 사용자 "안 하면 넘어가는 걸로"), 두 번 연속이면 진 판. ⚠ 지금 봇 3:3은 `{kind:'rest'}`를 평타로 바꿈(`playTurn3`의 "쉴 차례가 아니면 평타") — 1:1 · 사용자 규칙과 어긋나므로 봇 3:3도 넘어감으로 고침(화면은 시간 초과 · 쉬는 차례에만 rest를 보냄).
- 쓰러짐 · 승패는 지금 규칙 그대로(먼저 다 쓰러진 쪽이 짐, 같이 끝나는 일 없음 — 규칙 문서 §4).
- 앞 식물이 쓰러지면(팀에 남은 식물이 있으면) **턴 끝에 그쪽 사람이 다음 식물을 고름** — 둘 다 쓰러졌으면 둘 다 고름(서로 모르게, 둘 다 고르면 같이 공개). 고르는 시간 20초, 넘기면 살아 있는 첫 식물(시간 초과로 세지 않음). 턴을 쓰지 않음.

## 엔진(`v2/src/battle/team.js` · `v2/src/game/fight.js`)
- `playTurn3(B, myAct, foeAct = null)`: foeAct가 있으면 사람(봇 교체 · 봇 기술 고르기 없음, 난수도 안 씀). 기술: 쉬는 차례 = 쉬기, `rest` = 넘어감, 못 쓰면 평타. 교체 검사 = 나와 같음.
  - 끝: 봇 판 = 지금처럼(상대 자동 교체 · `B.need = 'me'`). 사람 판 = 자동 교체 없이 `B.need = 'me' | 'foe' | 'both' | null`.
- `sendIn(B, to, side = 'me')`: 'both'면 남은 쪽으로, 아니면 null.
- `setupPvp3({ seed, a, b, aName, bName })` · `pvpTurn3(B, aAct, bAct)`(서버 수 `{kind:'skill', id}`를 기술 객체로).
- `viewFor(B, 'b')` 3:3 뒤집기: team · act · pool · need(me↔foe, both 그대로) · 유닛 id · over. `turnFor`에 mySwitch ↔ foeSwitch. 교체 사건의 `to`는 번호라 `mirrorEvents`가 안 건드림(그대로 둠).
- 재생 결정론: 같은 씨앗 · 같은 수 → 같은 판(서버 시험으로 확인).

## 서버(`server/rooms.mjs` · `game.mjs` · `api.mjs`)
- 방: `mode`. 사람: `team`(식물 uid 셋) · `teamCards`. `refresh`가 팀도 다시 읽음.
- 새 길: `POST /api/room/mode { mode }`(방장 · 대기 중만), `POST /api/room/team { plants: [uid×3] }`(→ `game.act(uid, 'setTeam')` 저장 → refresh → 알림). `move`는 3:3이면 객체 수.
- 대결 단계 `r.sends`: null = 수 고르는 중, {} = 쓰러진 자리 채우는 중.
  - 고르기: `{kind:'skill', id}` · `{kind:'switch', to}` · `{kind:'rest'}` 검사 → 둘 다 오면 `resolve3`.
  - `resolve3`: 고른 수 세기 → `pvpTurn3` → 공개(앞 식물 번호 `r.shown`, 그 식물이 쓴 기술 `r.revealed[side][번호]`) → need면 `r.sends = {}` + 20초, 아니면 40초 → 둘에게 'turn' → 끝났으면 `end`.
  - 채우기: `{kind:'send', to}` → 필요한 쪽이 다 고르면 `applySends`: a 다음 b 순서로 `sendIn` → 공개 → 40초 → 둘에게 새 알림 **'send'** `{ sends(b에겐 뒤집음), view, deadline, now }`. 한쪽만 고르면 상대에게 'foeReady'.
  - 시계: 채우기 시간 넘김 = 자동(살아 있는 첫 식물), 고르기 시간 넘김 = `{kind:'rest'}` + 시간 초과 수(2번 = 'timeout' 패).
- `viewOf(r, side)` 3:3: 상대 팀 중 `shown`에 없는 식물 = `{ id:'foe', hidden:true, name:'?', key:null, hp: 살았으면 1 · 아니면 0, max:1, energyMax, kit:[], eff:{} }`, 나온 식물 = 기본기 + 그 식물이 쓴 기술만 · 능력치 null · st 줄임.
- `battleMsg` · `roomView`: `moved` = 고르기면 이번 수를 냈는지 · 채우기면 보냈는지, `step: 'pick' | 'send'`. roomView에 `mode`, 사람마다 `team3`(팀 셋이 되는지 — 상대 것도), 나에게만 `team`(카드 셋).
- `end`: `r.sends` 정리, 기록에 `mode`(3:3이면 `win`/`lose`가 식물 셋 배열). 보상은 1:1과 같음(`pvpResult`).
- `game.teamOf(uid, uids)`: 고른 셋 → 없거나 틀리면 저장된 팀 → 앞에서 셋, 셋이 안 되면 null.
- `server/report.mjs` 친구 대결 칸: 1:1 · 3:3 나눠 세고 배열을 받음.

## 화면
- `net/api.js` room에 `mode(m)` · `team(uids)`.
- `room.js`: 방장 = [1:1 | 3:3 교체전] 고르기(방장 아니면 글자만), 3:3이면 내 카드에 얼굴 셋 + '팀 바꾸기'(셋 고르는 창 — 누른 순서 = 앞에 설 순서), 상대 = '?'. 3:3인데 팀이 안 되면 준비 단추 막고 까닭 한 줄. 설명 글 = "친구와 대결 · 1:1 또는 3:3".
- `battle.js`(친구 대결 3:3):
  - 시작 · 다시 맞춤: need가 나(me · both) = 'need' + 교체 창(이미 보냈으면 'wait'), 상대만 = 'wait' + "상대가 다음 식물을 고르는 중".
  - 쓰러진 자리 고르기 → `R.move({kind:'send', to}, B.turn)` → 'wait'(실패면 다시 창).
  - 연출 중('play')에 온 알림은 줄 세워 두었다가 `finishTurn` 뒤에 처리(상대가 먼저 골라 'send'가 연출 중에 올 수 있음).
  - 'send' 알림 = 판 고치고 교체 연출들 → 다음 턴.
  - 채우는 창에 남은 초(친구 대결), 위 띠 = '친구 3:3 · 코드'.
- 시험: 엔진(사람 대 사람 무작위 1000판 — 끝남 · need 일관 · 같은 씨앗 재생 같음), 서버 API(두 계정이 방 → 3:3 → 무작위 수 · 교체 · 채우기 · 시간 초과로 끝까지), `tools/test/pvpfriend.mjs --mode swap3`.
