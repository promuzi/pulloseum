## 2. 이번 확정

- 버프와 디버프는 모두 **각 중첩 5턴/독립 만료**다. 재부여로 기존 겹의 시간을 갱신하지 않는다. 교체 중에도 전투 턴에 따라 기간을 진행한다. 체력은 수치 강화/약화에서 제외한다.
- **모든 상태이상은 교체 시 유지**하고 자기 기간을 계속 센다. 앞선 교체 시 일반 상태 제거/대면 상태 자동 삭제 추천을 그대로 적용하지 않는다. 상태마다 피해·회복·확률·연결이 실제로 대기 중에도 발동하는지는 별도 문제로 검토 대기에 둔다.
- **준비 효과는 교체 시 제거**한다. 집중/은신/보호막을 두고 반사를 제외한다. 보호막은 한 번 막으면 남은 보호량도 사라진다. 보호막이 연타의 첫 타를 뜻하는지 행동 전체인지는 문구만으로 확정하지 않는다.
- **반사는 방어 스킬**이다. 처음 맞는 한 타만 반사하고, 연타의 뒤 타는 반사하지 않는다. 안 맞아도 다음 턴에는 끝난다. 방어/회피/반사는 상태창 목록에 넣지 않고 **머리 위 방패/회피/반사 아이콘**으로 행동을 보여준다. 반사율과 방어·회피 동시 적용 세부까지 새로 확정하지 않는다.
- 가이아의 **희생의 성체만 소환수**, 나머지 철벽/모래성/회복/지옥 요새/움직이는 성은 **자기에게 유지되는 개인 환경**이다. 기존 수명 없음/유지비 0.5/부족 시 종료/주인 교체 시 종료 기록은 보존한다. 모래·지옥 요새의 적에게 미치는 기존 효과를 없애라는 뜻까지 확대하지 않고 적용 범위를 검토 대기에 둔다.
- 이전 만개·칼춤 등의 판 끝까지 남는 강화는 이번 **모든 버프 5턴** 방향과 충돌하므로 최신 공통 기간을 우선한다. 독립 만개 상태를 줄이는 안/종별 원안 인용/옛 수치표는 보존한다.

## 3. 엑셀 구성

- [검토용 엑셀](../../../outputs/01a151d0-9d92-7900-b5be-31a811469c9d/풀로세움_효과와스킬_분류.xlsx): **효과 분류 / 스킬 분류 / 검토 대기 / 미분류·잔여** 4시트.
- 효과 분류는 44행. 반복 대/중/소분류만 세로 병합하고 각 효과명/설명은 독립 셀이다. 정화 해제/지속 방식/기간(턴)/교체 시/소모·비고를 구별한다. 수치 증가 5종과 감소 5종은 모두 개별 행이다.
- 스킬 분류는 21행. 공격/방어/회복/서포팅/버프/디버프/상태이상/준비 효과/환경/함정/소환수로 묶었다. 공격과 다른 효과가 섞이면 대표는 공격이고 부가 효과를 함께 적는다.
- 검토 대기는 19행. 전환·제거·복사·소비·모으기·지연 공격·그 턴 버티기 7개 용어와 기절·마비·얼음·매혹 4개를 각각 뜻/기존 예시/분류 후보로 설명한다. 대기 중 상태 발동/연결/정화의 겹 처리 등 남은 공통 판정도 구별했다. 선택 칸은 유지·통합·삭제·보류로 고를 수 있다.
- 미분류·잔여는 8행. 불타는 의지 2회/일시 철벽의 직접 피해 감소와 기존 고유 자원·태세·기술 제한·불운 보정·패시브·기초 보정이 남는다. 가이아 일반 성체는 개인 환경으로 편입되어 이 목록에서 뺐다.

명칭은 **공격 증가 분노/방어 증가 강인함**을 사용자 예시로 반영하고, 기동 증가 가속은 기존 이름을 유지했다. 치명 확률 증가 예리함/정확도 증가 정밀함, 공격 감소 쇠약/기동 감소 둔화/치명 확률 감소 무딤 등은 명칭 제안이다. 방어 감소 부식은 기존 이름이며 교란은 정확도 감소로 정리하는 안이다. 기존 교란 기술이 기동도 낮추면 둔화도 함께 주는 조합으로 표현할 수 있다. 젖음 같은 복합 상태까지 수치 디버프로 중복 분해하지 않는다.

## 4. 흡수와 낯선 처리 용어

흡수는 독립 상태나 별도 작동 장치를 늘리기보다 **보조 분류**로 쓰는 안을 추천한다. 체력 흡혈은 공격 후 실제 체력 피해 비례 회복, 능력치 흡수는 상대 약화와 내 강화 조합으로 표현할 수 있다. 비율/흡수량/상대 정화 시 내 강화 종료 연동은 미정이다. 새 연동을 붙이지 않으면 각각의 5턴 효과로 처리할 수 있다.

전환·제거·복사·소비 등은 작업자가 기존 기술의 처리를 묶어 부른 말이며 새 사용자 기술을 만들었다는 뜻이 아니다. 전환은 스파크 태양광의 햇빛→전기, 제거는 정화/윤회/업화, 복사는 조화, 소비는 방출/타이드 피날레가 예다. 모으기·지연 공격은 현재 공통 장치 또는 미확정 초안에 있던 처리로, 통합 은신을 옛 자동 모으기로 되돌리지 않는다. 그 턴 버티기는 쏜위드 죽은 줄 알았나?의 해당 턴 조건부 반응을 가리켰다. 이번에는 모두 검토 시트에 두고 새 대표 분류로 확정하지 않는다.

## 5. 저장·검수 범위

엑셀은 사용자가 효과명·유지 여부를 판단할 검토 산출물로 원격에도 보관한다. [초안 데이터](../../../tools/design/effect-taxonomy-20261019/data.json)와 [작성기](../../../tools/design/effect-taxonomy-20261019/build.mjs)도 판단 근거로 함께 남긴다. 사용자가 엑셀을 직접 수정한 뒤에는 기존 수정 내용을 읽어 편집하며 작성기를 무조건 다시 실행해 덮지 않는다.

Artifact Tool에서 값/열/기간/누락/병합을 검사하고 미리보기를 생성했다. 도구 미리보기에서 세로 병합이 잘못 그려져, 파일 병합 범위와 실제 Excel의 읽기 전용 출력으로 4시트를 추가 확인했다. Excel에서 병합/한글/줄바꿈과 사용자 선택 칸을 확인했다. 출력 검사용 PDF/PNG와 임시 검사 파일은 전달물/원격 기록에서 제외한다. 게임 동작·승률·새 저장 형식은 구현/시험하지 않았다.
