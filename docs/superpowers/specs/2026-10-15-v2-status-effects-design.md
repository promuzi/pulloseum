## 2. 공통 규칙(추천)
1. **쉬는 타이밍 = "다음 행동 1번 취소".** 맞은 턴에 아직 안 움직였으면 그 행동이 취소(쓴 에너지는 돌려줌), 이미 움직였으면 다음 턴을 쉼. 빙결 3칸·감전 3칸·기절 모두 같음.
2. **연속 쉬기 막기('버팀').** 쉬고 난 다음 1턴은 쉬기 효과가 터지지 않음(빙결·감전은 칸만 쌓임, 기절은 안 걸림). 없으면 에너지를 모아 기절 → 기절로 상대가 아무것도 못 하는 판이 나옴(메카의 '녹는 중'과 같은 장치).
3. **걸리는 조건.** 빗나감 = 안 걸림 · 방어 자세가 성립해 막으면 안 걸림(방어의 쓸모) · 스침·정타 = 걸림 · 치명 = 칸 1개 더(빙결·감전·독).
4. **같은 속성 면역.** 불 식물 = 화상 X · 물 = 젖음 X · 번개 = 감전 X · 빙결 = 빙결 X.
5. **3:3 교체.** 독·화상은 따라감, 나머지(젖음·빙결 칸·감전 칸·기절·덩굴)는 교체하면 풀림 → '교체로 씻어 내기' 판단이 생김.
6. **효과가 붙은 기술은 위력을 조금 낮춤**(지속 피해·쉬기 값만큼).

## 3. 연계·상극(추천, 선택)
- 젖은 상대에게 감전·빙결 = 칸이 두 배로 참(물이 전기를 통하고 잘 얼음) → 3:3에서 "물로 적시고 번개로 교체" 같은 연계.
- 물에 맞으면 화상이 꺼짐 · 불에 맞으면 젖음·빙결이 녹음.

## 4. 효과를 주는 기술(추천)
- 불 = 화상 · 물 = 젖음 · 번개 = 감전 · 대지 = 기절(대표 기술만) · 가시·포자 = 독 · 덩굴·새순 = 덩굴 · 빙결 = 빙결(지금 빙결 식물 없음).
- 바람 = 빈자리 → §5 '꽃가루'(명중 ↓) 추천.
- 가벼운 기술(비용 1) = 1칸·짧게, 대표 기술(비용 3) = 2칸·길게.
