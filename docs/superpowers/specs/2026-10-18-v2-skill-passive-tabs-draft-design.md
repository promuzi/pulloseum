# v2 스킬 · 패시브 탭 분리 + 새 고르기 화면 (2026-10-18)

> 대기열 1번(기술 · 패시브 카드 개편)의 연장. 앞서 만든 카드 고르기(CHANGELOG 68 · `scenes/draft.js`)를 이 문서대로 다시 짠다.
> 사용자 원문은 따옴표, ⟨내 결정⟩ 표시는 사용자가 정하지 않아 내가 정한 것(사용자가 바꿀 수 있음).

## 1. 의도
- 사용자: "기본기 스킬도 6개 스킬 칸에 포함되어야 해 — 기본기 스킬 넣을 때 이미 스킬 꽉 차면 버려야 함" → 기본기도 칸을 차지하는 보통 카드. 지금은 전투 칸에 없는 기본기가 '늘 앎'으로 칸 밖(기본기 줄)에 있어 칸 수의 긴장이 없음.
- "패시브 3개로 늘리자 · 스킬 카드 / 패시브 카드를 다른 항목에서 선택하게 분리해 줘 아예."
- "스킬: 장착 6칸 · 보관 6칸(변이가 있다면 변이랑 6칸 모두 공유 가능 — 변이 카드는 테두리 등으로 차이)" · "패시브: 장착 3칸 · 보관(변이 패시브만) 3칸."
- "스킬과 패시브 획득 시에도 스킬 선택과 패시브 선택을 각각 순서대로 창이 떠서 진행" · "보류를 누르면 상단에 보류 버튼이 생김."
- 고르기 화면(진화 때 화면이 "맘에 안 들어"): "상단에는 얻은 거, 그 위에 몇 개 선택인지 · 아래에는 장착한 것과 보관이 다 있어서(기존 UI대로 비슷하게) · 드래그로 안 하고 장착 누른 후에 기존 거 눌러서 교환 · 바뀐 기존 거는 위에 올라가고 서로 빛나서 확인 · 확정 전까지는 되돌릴 수 있게 · 꾹 누르면 뒷면."
- 후보가 모자랄 때(CHANGELOG 68의 발견): 사용자 "(나)로 — 예전 것도 배울 수 있는 기회가 있으면 좋지, 물론 우선은 최신 거" · 기술은 사용자가 나중에 더 추가.

## 2. 목표 · 비목표 · 안 되는 것
- 목표: 위 규칙과 화면. 옛 세이브가 잃는 것 없이(또는 '지운 기술'로 되찾을 수 있게) 옮겨짐. 서버가 모든 배치를 검사(화면을 믿지 않음).
- 비목표: 카드 · 기술 수치 밸런스(사용자 몫) · 새 기술 추가(사용자 몫) · 접목 화면을 카드 형식으로 바꾸기(대기열 3번 — 다만 아래 §3.6처럼 접목 · 회귀로 배운 기술이 칸이 없으면 같은 고르기 화면으로 감).
- 안 되는 것: 고르기 화면에서 끌어 놓기(사용자가 뺌) · 화면에만 있고 서버가 모르는 배치 · 카드(물건)가 사라짐(밀려난 카드는 가방으로).

## 3. 규칙(`v2/src/game/` — 서버 · 화면 공용)
### 3.1 스킬 칸
- `p.skills.battle` = 장착 6칸(빈 칸 null) · `p.skills.store` = 보관 최대 6(빈 칸 없이 차례대로).
- 들어갈 수 있는 것: 배운 기술 · **기본기 넷**(basic · guard · evade · sun) · 변이 식물의 그 변이 기술 카드(장착엔 `MUT_MAX`=2장까지, 보관엔 6칸 안에서 제한 없음).
- 기본기 = 보통 기술처럼 칸을 차지. 장착 · 보관 어디에도 없으면 '지운 기술'(`p.skills.forgot`)에 있는 것 — 유전자 회귀 주사로 되찾음.
- 장착에 기술이 하나는 있어야 함(지금 규칙 그대로).
- 변이 기술 카드는 물건: 식물 칸(장착 · 보관)에 들어가면 가방(`s.cards`)에서 빠지고, 밀려나거나 빼면 가방으로.

### 3.2 패시브 칸
- `p.cards` = 장착 3칸(`CARD_SLOTS` 2 → 3) · `p.pstore` = 패시브 보관 최대 3(새 칸).
- ⟨내 결정 — 사용자 "보관(변이 패시브만)"의 해석⟩ **일반 패시브는 모든 식물이 끼움(변이 식물도)** · 변이 패시브는 그 변이 식물만 · **패시브 보관 = 그 변이 패시브만**(변이 식물만 있음 — 변이마다 패시브가 셋이라 장착 · 보관을 다 써도 맞음). 일반 패시브 중 안 끼운 것은 가방에. → `cardFits` 의 '변이 식물은 그 변이 카드만'을 바꿈(2026-10-17 결정 변경).
- 패시브도 물건: 장착 · 보관에 들어가면 가방에서 빠지고, 빼면 가방으로. 한 식물에 같은 카드 두 장 없음.

### 3.3 탭에서 옮기기 — `setSlots(s, id, { battle, store, cards, pstore })`
- 화면이 네 배열 전부를 보냄. 서버 검사: 길이(6 · ≤6 · 3 · ≤3) · 기본 기술(배운 기술 + 기본기)은 **원래 식물 칸에 있던 것만, 하나도 빠짐없이**(탭에서는 버리지 않음 — 버리기는 고르기 화면에서만) · 카드는 맞는 것만(`cardFits` · 보관 패시브는 변이 패시브만 · 장착 변이 기술 카드 ≤ `MUT_MAX`) · 새로 들어온 카드는 가방에 있어야 하고 가방에서 빠짐 · 빠진 카드는 가방으로 · 같은 것 두 칸 없음 · 장착에 하나는 있음.
- 옛 일 이름(`setSlots(s, id, battle, cards)` · `setCards`)도 받음(옛 화면이 열려 있을 수 있음 — store/pstore는 그대로 두고 규칙 검사만).

### 3.4 고르기(드래프트)
- `p.drafts = [{ kind, part, st, lv, pick, cands }]` — `part` = `'skill'` | `'passive'`(새 칸 — 옛 고르기는 `'skill'`).
- 언제 · 몇 장(사용자 결정 그대로): 레벨업 = 기술 셋 중 하나 · 단계 끝 레벨(Lv6 · 11 · 16) = 넷 중 둘 · 진화 = 넷 중 둘 · 마지막 진화 = 다섯 중 셋.
- ⟨내 결정⟩ **패시브 고르기 = 진화 · 단계 끝 레벨에서만, 셋 중 하나**(레벨업마다면 3칸이 금방 참). 같은 일에서 기술 고르기 다음에 패시브 고르기(배열 차례 = 화면 차례).
- 기술 후보(사용자 (나)): 그 단계에 피는 것(`bloomPool(key, stage)`) 중 모르는 것 · 무게 그대로 + **앞 단계들에 피는 것 중 모르는 것 · 무게 ¼**(⟨내 결정⟩ 수치). 다른 고르기에 이미 나온 것 · 지운 기술 · 기본기는 뺌. 후보가 없으면 고르기 없음(지금처럼).
- 패시브 후보: 일반 식물 = 일반 패시브 중 그 식물에 없는 것 · 변이 식물 = 그 변이 패시브 중 없는 것(무게 3) + 일반 패시브 중 없는 것(무게 1) ⟨내 결정⟩. 고른 패시브는 새로 생기는 카드(가방에서 빼는 것이 아님).
- 후보 · 차례는 식물 · 단계 · 레벨로 정한 씨앗(지금처럼 — 화면이 먼저 해도 서버와 같게).
- **확정 = `draftApply(s, id, n, layout)`** — 기술 고르기면 `{ battle, store }`, 패시브 고르기면 `{ cards, pstore }`. 서버 검사: 새 배치의 것은 (원래 칸의 것 ∪ 후보)에서만 · 후보는 정확히 `pick` 장(후보 수가 더 적으면 그 수) · 칸 규칙(§3.1 · §3.2) · 빠진 배운 기술 · 기본기 → '지운 기술' · 빠진 카드 → 가방 · 안 고른 후보는 없어짐. 결과 = `{ got: [...], dropped: [...] }`.
- 옛 일 `draftPick(s, id, n, picks)`도 남김(옛 화면용 — 고른 것을 빈 칸 → 보관 → 그래도 없으면 버티지 말고 오류 '칸이 다 찼어요').

### 3.5 옛 세이브(`normSkills` v8 · `normCards`) — 한 번
- 장착에 없는 기본기 → 보관 빈 칸으로(회피 · 광합성 · 방어 · 평타 순으로 덜 중요한 것부터 밀리지 않게 ⟨내 결정: 평타 · 방어 · 회피 · 광합성 순으로 먼저 넣음⟩) · 보관이 차서 못 들어간 기본기 → '지운 기술'.
- `p.pend`(놓을 칸을 기다리던 새 기술) → 하나씩 고르기(`kind: 'one'`, `pick: 1`, `cands: [id]`)로.
- `p.cards` 길이 3 · `p.pstore = []`.

### 3.6 다른 데서 배우기(`learnNow` — 첫 식물 · 접목 · 회귀)
- 빈 장착 칸 → 보관 빈 칸 → 그래도 없으면 고르기 하나(`kind: 'one'`)를 만들어 고르기 화면에서 놓게(더는 `p.pend` 를 쓰지 않음 · '새로 핀 기술' 칸 없앰).

## 4. 화면
### 4.1 식물 관리 탭
- 탭 다섯: **스킬 · 패시브 · 강화 · 개체값 · 설정**.
- 스킬 탭: 장착 6 → 보관 6 → (변이 식물) 가방의 그 변이 기술 카드 줄. 기본기 줄 · '새로 핀 기술' 칸은 없앰. 누르기 · [장착]/[해제] · 꾹 끌어 놓기는 지금 그대로(탭에서는 끌기 유지). 해제할 때 보관이 꽉 차 있으면 '보관이 꽉 찼어요'.
- 패시브 탭: 장착 3 → (변이 식물) 보관 3 → 가방의 맞는 패시브 줄.
- 변이 카드 구분: 지금 각진 갑옷 테(변이 색 · 모서리 징)를 그대로 쓰되 촬영으로 보고 약하면 테 색을 진하게 ⟨빌더 판단⟩.
- 지운 기술 · 접목 가지 단추는 스킬 탭 아래.

### 4.2 고르기 화면(`scenes/draft.js` 다시 짬)
- 위에서부터: 제목(`Lv14` · `진화`) → **"N장 고르기 · k/N"** → **위 줄 = 얻은 카드**(후보 + 밀려 올라온 기존 카드) → 아래 = **장착 칸 → 보관 칸**(식물 관리 탭과 같은 배치 · 3장씩 줄 · 66×90 카드) → 맨 아래 단추 줄 **[되돌리기] [보류] [확정]**.
- 아래 칸 영역은 화면보다 길면 위아래로 끌어 넘김(위 줄 · 단추는 고정).
- 누르기: 위 줄 카드 누름 → 고른 표시 + **[장착]** 단추 → [장착] 누름 → 놓을 수 있는 칸이 금빛으로 숨 쉼 → 칸 누름: 빈 칸 = 채움 · 찬 칸 = 서로 바꿈(원래 카드는 위 줄로 올라감) → 들어간 카드와 올라간 카드가 **같이 빛남**(잠깐 · 다음 움직임까지).
- 위 줄의 밀려 올라온 기존 카드도 같은 방법으로 다른 칸에 다시 놓을 수 있음(후보 장 수에 안 셈).
- 아래 칸의 카드끼리 자리 바꾸기는 ⟨내 결정⟩ 안 함(탭에서 함 — 화면을 단순하게).
- **꾹** = 그 카드 뒷면 크게(식물 관리 탭의 뒷면 보기와 같은 움직임) · 떼면 닫힘.
- **[되돌리기]** = 한 단계씩(처음 상태까지) · **[확정]** = 후보를 정해진 장 수만큼 놓았을 때만 켜짐 · 위 줄에 남은 기존 카드가 있으면 확인 창 "○○ · ○○를 버려요(지운 기술로)" ⟨내 결정⟩ · **[보류]** = 닫고 맨 위 '보류' 단추로.
- 진화는 지금 진화 연출 → 이 화면. 기술 고르기 확정 뒤 같은 식물의 다음 고르기(패시브 등)가 바로 이어서.
- 규칙 위반은 화면이 먼저 막고 알림 띠(변이 기술 카드 장착 2장 · 일반 패시브는 패시브 보관 불가 · 장착에 하나는).

### 4.3 맨 위 '보류' 단추
- 고르기가 남은 식물이 있으면 홈 · 스마트팜 · 식물 관리 · 보관고 화면 맨 위 띠 근처에 작은 **'보류 N'** 단추(N = 남은 고르기 수 합) — 누르면 그 식물(첫 번째)의 고르기 화면. 전투 · 탐사 연출 중엔 없음. 정확한 자리는 촬영으로 겹치지 않는 곳 ⟨빌더 판단⟩. 기술 탭의 '스킬 정하기' 단추는 없앰(이 단추로 대신) · 빨간 점은 유지.
