# v2 변이 연출 설계 — 외형을 다시 그리지 않고 변이를 보이게 (2026-10-15)

> 사용자 결정(2026-10-15): "변이도 넣어서 출시할 거야 — 외형 변화가 없더라도 어떻게 넣고 연출할지 고민". 2026-10-14 "변이 카드는 첫 출시 제외"를 뒤집음 → 결정 로그.
> 시스템 규칙은 그대로 따른다: 변이형 6종(일반·포식·무기·독성·포자(버섯 전용)·용족), **변이형 = 패시브 없는 카드 슬롯 문**, 식물당 1개, 포식·무기·독성·용족은 **아래 변이 스킬 바**, 포자는 턴 끝 자동 발동 → [변이 재설계](2026-06-24-mutation-forms-cards-redesign-design.md).

## 0. 근거(자료)
- **포켓몬 색다른 모습(Shiny):** 몸을 새로 만들지 않고 색만 바꾸며, **전투에 나올 때 별·빛이 번쩍이는 짧은 연출과 '핑' 소리**로 알린다. 상태 화면에도 별 표시 → [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Shiny_Pok%C3%A9mon), [Serebii 등장 연출](https://www.serebii.net/games/entryanimation.shtml).
- **가챠 공개 연출:** 색·움직임·소리가 함께 희귀도를 알리고 기대를 키운다. **색이 먼저 오고 결과가 나중에** 온다(낮음 = 차갑고 조용, 높음 = 금빛·무지개·화면을 덮는 빛) → [TMU 시각문화 글](https://pressbooks.library.torontomu.ca/visualculture-howtosee/chapter/chapter-6/), [가챠 색 문법](https://hostedgg.com/blog/gacha-pull-reveal-color-culture).
- **카드 게임 희귀도 테두리**(같은 그림에 테두리·입자 밀도로 등급 표시) — 같은 원리.
- 효과 제작 근거는 saint11 강좌(광택·보석·불·물·바람·타격) — `tools/pixel/big/fx.mjs`·`attack.mjs`.

## 1. 원칙
1. **식물 그림은 하나만** — 변이는 그림 위에 얹는 **연출 층**으로 보인다(종별 변이 그림 140장을 새로 만들지 않음).
2. **변이형마다 색·모양 하나씩 고정**(알아보기 쉽게): 포식 = 진홍·송곳니, 무기 = 강철·칼날 빛, 독성 = 보라·거품, 포자 = 금빛 포자, 용족 = 청록·비늘. 일반(무변이)은 없음.
3. **자주 보는 곳은 은은하게, 드문 순간은 크게** — 대기 화면에선 테두리 빛과 작은 입자만, 발견·첫 등장·변이 스킬 순간에만 큰 연출.
4. 사용자 지시대로 상대의 다음 수는 공개하지 않는다(변이 스킬 예고 금지 — 로드맵 결정 2026-09-11).

## 2. 연출 층
| 층 | 언제 | 무엇 | 비용 |
|---|---|---|---|
| ① 테두리 빛 | 늘(목록·도감·전투·양육) | 식물 외곽선 중 빛 받는 쪽 1칸을 변이 색으로 40% 섞음 — 그림은 그대로, 한눈에 "변이체" | 낮음: 외곽선 칸은 변환기가 이미 앎 → 마스크 PNG 하나 |
| ② 문장(엠블럼) | 이름 옆·카드·정보 상자 | 9×9 도트 문장 5종(송곳니·칼·독방울·포자·비늘) | 낮음: `art/icons.js`에 5개 |
| ③ 은은한 기운 | 대기 동작 | 변이형별 입자: 포식 = 눈에 진홍 반짝 + 진홍 입자, 무기 = 몸 위 강철 광택 쓸기, 독성 = 밑동에서 보라 거품, 포자 = 금빛 포자 떠오름, 용족 = 비늘 반짝임 사선 + 작은 숨결 | 중간: `fx.mjs` 재사용(shine·twinkle·bubbles·spores) |
| ④ 발견 공개 | 탐사 결과에서 변이 종자를 얻을 때 | **색이 먼저**: 종자 캡슐이 변이 색으로 떨리며 빛이 새고(0.6초) → 흰 번쩍 → 식물이 기운과 함께 나타나며 문장이 도장처럼 찍힘(0.8초) → 이름·변이형 글자. 1.5~2초, 누르면 넘김 | 중간 |
| ⑤ 첫 등장 | 전투 입장 때 변이체 | 포켓몬 색다른 모습처럼 **0.6초 변이형 폭발 + 소리**: 포식 = 진홍 눈빛·이빨 다무는 입자, 무기 = 칼날 빛 두 줄 교차, 독성 = 거품 터짐, 포자 = 포자 퍼프, 용족 = 비늘 번쩍 + 화면 살짝 흔들림 | 중간 |
| ⑥ 변이 스킬 | 아래 변이 바 기술을 쓸 때 | 포식 = 두 초승달이 물듯 닫힘 + 빨려 오는 진홍 빛(흡혈), 무기 = 무기 종류별 베기·찌르기·총구 섬광, 독성 = 독방울 + 독 칸 눈금, 용족 = 자기 속성 숨결(불·물·번개…) / 비늘 = 육각 방패 번쩍, 포자 = 턴 끝 적에게 포자 퍼프 + 디버프 아이콘 | 높음(기술마다) — 첫 출시엔 변이형당 1개씩 |
| ⑦ 도감 | 도감 상세 | 발견한 변이형을 문장 줄로, 누르면 ③ 기운 미리보기 | 낮음 |

## 3. 첫 출시 범위(추천)
- **반드시:** ① 테두리 빛 · ② 문장 · ④ 발견 공개 · ⑤ 첫 등장 · ⑥ 변이형당 기본 변이 스킬 연출 1개(포식 = 물기, 무기 = 검 베기, 독성 = 독 뿌리기, 용족 = 숨결, 포자 = 퍼프).
- **나중:** ③ 대기 기운(성능·산만함 확인 후) · ⑥ 카드별 세부 연출 · ⑦ 도감 미리보기.

## 4. v2에 넣는 방법
- 데이터: v1의 `p.form`(= `base_variants[0]`)·`formsOf(p)`를 v2 `mock`/세이브에서 그대로 읽는다.
- 그림: 변환기가 종마다 내보낼 것 = 대기 시트(64장) + **외곽선 마스크**(테두리 빛용) + 공격 시트. 변이 층은 v2가 그릴 때 덧칠(테두리 색 섞기·입자) — 변이형별 시트를 따로 굽지 않는다.
- 소리: 발견·첫 등장에 변이형별 짧은 효과음(포켓몬 '핑'처럼 한 귀에 구별) — 사운드 작업 때.
