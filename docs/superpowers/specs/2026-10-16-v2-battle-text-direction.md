# v2 전투 글자 연출 — 출력 문구 목록 (2026-10-16)

사용자: "가운데 문구가 이상해. 네모난 배경색에 무엇을 할까? 이것도 어색해. 일일이 이런 문구 넣지 말아줘." → "출력 문구 목록도 정리해봐. 효과나 폰트 등도 고려하고. 연출적으로".

## 원칙
- **가운데 네모 전광판 없음.** 매 단계 서술 문장('○○의 ○○!', '먼저 움직인다!', '무엇을 할까?')을 띄우지 않는다.
- 글자는 **그 일이 일어난 식물 머리 위에서만, 한두 낱말**로. 무슨 일인지는 그림(공격 연출 · 피격 흔들림 · 체력 막대 · 효과 창)이 먼저 말하고 글자는 거든다.
- 크기 = 중요도. 피해 숫자 > 판정·효과 낱말 > 기술 이름 리본. 승패만 가운데 큰 글자.
- 글꼴 = 프리텐다드(도트 글자 금지 규칙 그대로), 모든 글자에 짙은 먹선(밝은 경기장 위에서도 읽히게).
- 서술 문장(`buildSteps`의 `msg`)은 지우지 않고 기록용으로 남김 — 나중에 '전투 기록' 창을 만들면 그대로 쓴다.
