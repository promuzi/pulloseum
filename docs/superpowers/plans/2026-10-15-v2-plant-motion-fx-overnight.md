# v2 식물 움직임·효과·공격·변이 연출 — 밤샘 작업 계획 (2026-10-15)

> 사용자 지시(잠자기 전): "불·전기 외에도 여러 이펙트 소스를 참고해 다른 속성(바람·물 등)에도 적용하고, 각 식물의 특성을 살려 디테일을 살릴 움직임·효과를 고려하며 다듬어 — 단단한 금속 재질은 반짝임·유광, 미끄덩한지 덩굴인지 등 다양하게", "눈감기도 계속", "각 식물별 공격 스킬 모션과 효과도", "멈추지 말고 알아서, 중요한 선택이 아닌 건 추천대로", "게임성과 UI도 자료를 참고하며, 서브에이전트는 최대한 쓰지 마", "변이도 넣어서 출시 — 외형 변화가 없더라도 어떻게 넣고 연출할지 고민".
> 이어받기: 이 파일의 체크박스와 맨 아래 진행 기록부터 본다. 도구 = `tools/pixel/big/`(convert.mjs·motion.mjs·video.mjs), 결과 = `out/conv/`.

## 단계
- [ ] 0. 결정 기록 — 변이 첫 출시 포함(2026-10-14 "변이 카드는 첫 출시 제외"를 사용자가 뒤집음) → 로드맵 결정 로그·CHANGELOG
- [ ] 1. 나머지 8종 변환(손타래·아쿠아벌브·윈드페탈·타이드바인·가이아록·게일캑터스·게일바인·스포어캡) — 화분 지우기는 색 규칙(무료) 먼저, 밑동이 깨지는 종만 코덱스 누끼(장당 5시간 한도 약 3%p)
- [ ] 2. 깜빡임 확장 — 원본 해상도에서 눈을 찾아 판으로 옮기기(96칸 판 눈 찾기는 꽃잎으로 번짐), 12종 눈 좌표(eyes.mjs)
- [ ] 3. 속성·재질 효과 묶음(자료 근거) — 물(물방울 맺혀 떨어짐·젖은 윤기·속 거품), 바람(바람결 선·날리는 꽃잎·소용돌이), 대지(먼지·무거운 숨), 풀(꽃가루·잎), 금속·수정(반짝 쓸기·별 반짝), 미끄덩(젤리 출렁임·윤기), 덩굴(물결이 끝으로 번지는 휨), 포자(떠오르는 포자 구름)
- [ ] 4. 12종 대기 동작 영상(종별 특성 설정 FX) + 4종 격자 3장
- [ ] 5. 공격 모션 + 스킬 효과 — 종마다 대표 공격 1개(준비 → 타격 → 멈칫 → 복귀) + 속성 효과(투사체·충돌·상대 피격 반응), 속성 성질(#14: 화상·침식·가시·감전·둔화·교란) 시각화
- [ ] 6. 변이 연출 설계 + 시제품 — 외형 변화 없이: 변이형별 기운(테두리 빛·입자), 발견·발현 연출, UI 표시(이름 옆 문장·카드 테두리), 전투 중 변이 스킬 발동 연출
- [ ] 7. 게임성·UI 자료 정리 — 타격감(히트스톱·흔들림·숫자), 대기·공격 연출을 v2 전투 화면에 넣는 방법(스프라이트 시트 규격)
- [ ] 8. 자동화 스킬 — 컨셉(코덱스 3번 방식) → 변환 → 눈 → 생장 → 대기·효과 → 공격 → 검토판 → MP4 → 커밋
- [ ] 9. 아침 보고 — 영상·검토판 SendUserFile, 요약
