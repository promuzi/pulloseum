**현재 작업(v2, 2026-10-21):** 오늘 확정까지 [효과·스킬 분류 v10](../../outputs/01a151d0-9d92-7900-b5be-31a811469c9d/풀로세움_효과와스킬_분류_v10.xlsx)에 반영했다(미결은 비움, 검토 대기 미결 0, 바탕화면에는 v10만). 암실은 스킬별 기간·다음 자연 햇빛부터 차단, 구름(옛 그늘 상태)은 암실의 다른 이름·연출, 면역은 다음 행동 한 번 보장 후 종료, 1턴 묶음은 제한(봉인·속박·도발)으로 확정했고, 암실은 지금 N턴, 행동 한 번으로 끝나는 건 일회성, 치명 준비는 조준으로 정했고, 기간 표기(지금·다음·일회성·지연·재사용 대기), 기절(비데미지 칸), 속박 단독 스킬(규칙 없음)까지 넣었고, B21 속박 재부여·1:1, B29 불 해제 없음, 포자 = 따로 쌓이는 지연 효과도 확정, 그늘(식물 하나)·구름/밤(전장)으로 이름을 바로잡고 전장 쪽 방향은 보류, 갈증(화상+암실 매 턴 갱신)·지옥 불(화상 최대 2겹)·둘의 연결(화상을 따라감)·기생·재생 기간·모래바람(상대 쪽에만)까지 확정해 v9에 넣었고, 봉인의 기본기 포함(다 막히면 쉼)·쉰 다음 턴 면역·기간형 상태이상 재부여(긴 쪽)·같은 환경 재사용 불가·준비 효과 N회(불타는 의지·남은 횟수)·철벽의 억셈 통합·미분류 남은 넷의 분류 밖 유지·자세는 그 턴 모든 타(연타 = 회피에 강한 안정형)·회복 방해는 출혈에만·면역 중 감전은 그대로 판정(터지면 면역이 막고 감전 소멸)·의지(기절·봉인·속박·도발을 확률로 막음)까지 확정해 v10에 넣었다. 강제 교체 때 기절·면역은 강제 교체 기술 때, 장소 자체 환경과의 우선순위는 그 기능 때로 미뤘고 효과 분류의 작은 미결은 모두 끝났다. 전투 시뮬레이션 테스트 방법은 [조사 문서](../superpowers/specs/2026-10-21-battle-sim-testing-research.md). 고유 기술은 사용자가 컨셉을 주면 하나씩 함께 짠다(2026-10-21) — **11번 게일바인 기술 여섯 설계 완료**(적용 대기). 다음부터는 클로드가 한 종씩 컨셉 그림·정보를 띄우고 사용자가 컨셉을 정하는 핑퐁 방식, **10번 게일캑터 · 12번 스포어캡도 설계 완료**, **13번 프로스트벨**은 타고남(메아리) 확정 · 기술 여섯은 초안(사용자 검토 대기)(표의 10~46번 중 사용자 원안이 없는 종은 클로드 초안). [최신 인계](../superpowers/specs/2026-10-20-v4-effects-workbook-handoff.md)·[최근 맥락](../superpowers/specs/2026-10-16-v2-mvp-design.md) 우선.

**확정/반영 범위:** 봉인·속박·도발의 다음 턴1턴 적용, 도발의 공격만 허용·교체 금지/햇빛 부족 시 무료 기본공격, 반사1타·보호막/집중의 기술1회 적용, 범위공격의 높은 명중률·비용 증가 우선, 연타·단타 역할, 기절 대표 태그, 대기 중 발동, 면역 범위, 모든 겹 제거, 착취, 환경 공존을 **v5 엑셀에 반영**했다. 게임 코드·배포 없음, 수치·미결은 임의 확정하지 않는다. 이전 확정·버린 안·미결은 인계와 아래 결정 로그에 보존했다.

- [ ] **범위공격 표현 개선 — 나중에:** 범위공격다운 모션과 스킬카드 우측 상단 폭탄 아이콘을 명확히 개선한다. 최종 아이콘 모양은 미정이며 지금 제작·적용하지 않는다.
- [ ] **카드 설명의 효과 조회 — 나중에:** 정한 효과·태그 명칭으로 카드 설명을 쓰고 해당 명칭을 눌러 효과 설명을 볼 수 있게 하는 방안을 검토한다. 공통 설명 재사용·표시 방식은 후속 설계, 지금 제작하지 않는다. **2026-10-24 사용자 보충:** ‘설명칸에 태그 붙이는 거 고민해줘 / 예로 연타 밑줄 치고 누르거나 하면 설명 나오는거 / 화상/기절/광역 이런거 / 지금은 하지말고 기록했다가 나중에’ — 카드 뒷면 설명 글 속 낱말(연타 · 화상 · 기절 · 광역 등)에 밑줄 태그를 달고 누르면 그 뜻이 뜨게. 카드 뒷면이 좁아 글이 넘치던 문제(CHANGELOG 247)도 태그로 설명을 접으면 같이 풀림.

#### 1-A. 변이 개체 정체성 (아키타입 축) — 🟡 1차 구현 완료, 외형·스킬효과는 후속
> 같은 타입+속성이라도 변이형마다 별개 개체 → **컨셉·스탯·고유스킬이 달라야 함**. form은 큰 틀(주요 스킬=변이카드)만, 진짜 차별화는 **개체 정체성**. (form 하나로 획일화 금지)
> **모델:** `개체 = 타입 × 속성 × 변이형(form) × 아키타입(personality)`. 아키타입은 form과 독립 → 같은 무기형이라도 광폭/도사 공존.

### 2. 식물 양육 / 열매 시스템 ⭐ 핵심
**비전:** 전투와 분리된 **양육 루프**. 식물을 키워 **열매**를 맺고 보상(소모품·스킬·변이 카드)을 얻는 방치형 감성의 축.
> 📄 **설계 박제: [superpowers/specs/2026-06-24-nurture-fruit-system-design.md](../superpowers/specs/2026-06-24-nurture-fruit-system-design.md)** — 브레인스토밍 진행 중. **재개 시 이 문서부터.**

**확정 골격(2026-06-24 브레인스토밍):**
- **생장과 열매는 분리된 2축.** 생장(진화)=경험치/레벨업, **열매=시간 경과+환경(물·비료·화분)**. 경험치는 열매와 무관.
- **열매는 성장체부터.** 그 이전(씨앗·새싹·유체)은 **낙엽=하위 소모품**만.
- **환경 레버:** 물/비료(양)→열매 **질 확률↑(상한·보수적, 다 줘도 전부 S 아님)**, 화분(품질)→**주기 단축**. 즉시수확=**미네랄**. 비료종류·환경=보류.
- **수확 보상 희소도:** 흔함=**소모품**, 희귀=**변이 카드(본인 변이형, 타 식물에도 장착 가능=전파)** / **본인 스킬(자기 전용 풀 확장, 전파 X)**.
- **화분 = 양육 전용**(전투 스탯 무영향). 페이지: 양육=4번째, 탐사선=5번째.

**열린 질문(스펙 §3):** 소모품 종류 + **물/비료 자급 순환 루프** 살릴지 / 단계 점증 영향 / 수확 단위 / 수치 / 본인 스킬 상한.
**구현 메모:** 식물에 `fruit` 상태 필드 신설 + `normalizeState` 마이그레이션(무회귀). 수확 연출 `#evolveModal` 재활용. 식물/화분 2레이어 분리(#12·#3 전제).

> 🟢 **1차 구현 완료(2026-06-26).** 설계 확정·박제 → [signature spec](../superpowers/specs/2026-06-26-element-signature-effects-design.md). 부여 범위·7성질·공통 규칙·UI 전부 확정 후 구현. `__catalogSelfTest()` 0 fail/103 + preview 실전투 7속성 검증. **남은 것 = 수치 밸런스 패스**(아래 메모).
