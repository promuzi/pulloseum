## 1장. 한 파일짜리 웹게임 (2026-06-15 ~ 06-27)

- **시작:** 바탕화면의 `풀로세움 기획서.pdf`를 기준으로, 이미 있던 웹게임(탐사 · 종자 · 성장)을 크게 업그레이드했다. 그때 문제 = 전투가 고정 4스킬이라 식물 특성이 전투에 안 드러남 · 콜로세움인데 토너먼트가 없음. → 속성 상성표 · 스킬 6칸 로드아웃 · 상태이상 엔진 · 토너먼트(2026-06-15).
- **한 파일:** 게임 전체(코드 + 데이터)가 `index.html` 하나. 설치도 빌드도 없이 브라우저에서 돌았다(루트 `README.md`의 소개가 이때 것).
- **열흘 동안:** 상단 인터페이스 · 생장 단계 외형 · 탐사선 4스탯 · 전투 카드 화면 · 식물원(양육) · 떠 있는 도트 UI · 갈무리 픽셀 글꼴 · 도감 · 양육 / 열매 · 탐사 아틀라스(11행성 · 4궤도 · 폴드 연출) · 버섯 7속성 · 스킬 태그와 시너지 · 속성별 시그니처 상태이상 · 이중 변이 버섯 28종 · 탐사선 격납고 UI.
- **릴스 장면:** 기획서 한 장 → 하루에 기능 서너 개씩 붙는 빠른 몽타주.
- **그림:** 기획서 원본 페이지 `_analysis/pdf_pages/page_01~10.png`(한 장 모음 `contact_sheet.jpg`) · 다음 기획 `_analysis/plan_v2/page-01~10.png`(2026-06-18) · 옛 판 대표 그림 `assets/icons/og-image.png` · 옛 판 실제 화면 = https://promuzi.github.io/pulloseum/ (지금도 열림 — 화면 녹화 가능).

## 2장. 재미를 다시 묻다 — 전투 코어 재설계 (2026-07-02)

- **무슨 일:** 3:3 팀전 · 교체 심리전 · 손패 4장 순환 · 봇 성향 표시 · 큰 기술 ⚠ 예고로 전투를 다시 짰다.
- **전환점:** 직접 해 본 뒤 손패 순환을 없애고, 사용자 판단 — 한 식물에 들이는 정성(변이 · 강화 · 스킬)이 게임의 축인데 3:3 주력은 그 정성을 세 배로 나눈다 → **1:1 주력으로 되돌림**, 3:3은 보조 리그.
- **릴스 장면:** "크게 뜯어고쳤다가, 직접 해 보고 되돌린 날".

## 3장. "1주일 안에 플레이스토어" (2026-09-10 ~ 09-11)

- **무슨 일:** 1주일 출시 목표로 여러 게임 중 풀로세움을 골랐다. 플레이스토어 개인 계정은 테스터 12명 × 14일 비공개 테스트가 먼저라는 벽을 확인.
- **그림 방향:** 레트로 도트 48×56 · 표시는 정수배(48 · 96 · 144) · 외곽선은 색마다 어두운 톤 · 눈은 2×2 점. 마스코트 같은 카툰 · 초롱 눈은 거절.
- **실패 → 교체:** 모티프를 모르는 AI 판독기에게 "뭐로 보이냐"를 묻는 블라인드 판독 — 코브라가 버섯구름 · 유령 · 토네이도로 읽혀 세 번 실패 → 아쿠아벌브는 '고사리 새순 해마'로 바뀜. 심미 판정은 결국 사용자(1차 형태 유지).
- **UX:** 첫 세션 재배선 · 가독성(12px 아래 글자 0) · 전투 피드백(1턴 6.0초 → 4.4초 · 히트스톱 · 넉백) · 정리.
- **되돌림:** 상대의 다음 수를 보여 주던 것을 PvP를 위해 비공개로 되돌림(2026-09-11).
- **그림:** 레트로 5종 `assets/sprites/*.png` · 렌더러 v2 산출 `tools/pixel/out/` · 조사 보고서 [sprite-quality-research.md](../sprite-quality-research.md) · UX 진단 [ux-audit](../superpowers/specs/2026-09-10-ux-audit-and-design.md).

## 4장. 전부 다시 — v2 도트 재제작 (2026-10-14 ~ 10-15)

- **결정(2026-10-14):** 옛 화면은 고쳐 쓰지 않고 `v2/`에 새로 짓는다. 그림은 전부 도트. 글자는 처음엔 도트였다가 "도트 글자가 깨진다"는 말에 프리텐다드 고해상도로.
- **전환점:** 새로 그린 식물을 본 사용자 — 식물이 **"밤티"**. 메카 프로젝트의 몬스터(약 190×134칸 · 부위별 입체 명암)와 비교해 해상도가 1/14 수준 → 96×112 큰 판으로.
- **방법 찾기:** 클로드 직접 작화(96×112 페탈로즈 시범) · 파스텔 색 선택지 → **코덱스가 그린 컨셉 아트를 그대로 96×112 도트로 변환**으로 확정(2026-10-15). 12종 변환 · 가상 3D 배치 · 흙 덮기 · 화분 앞뒤 깊이 · 눈 타원 직접 측정 · 대기 동작 · 종별 특성 효과 · 공격 12종 · 변이 연출.
- **배경 톤:** 시안 셋을 고르지 않고 "장소에 따라 다 적용"(우주선 · 온실 · 밤 정원 · 관중석 경기장) → 그림을 보고 **"너무 화려한데 톤과 그림을 좀 바꿔줘. 약간 레트로 느낌의 우주선에 투박한 느낌."** → 네온 · 오로라 · 광택을 빼고 낡은 금속판 · 리벳 · 경고등으로.
- **같은 날:** v2 전투가 실제 규칙으로 처음 싸워짐 · 선공은 기동 확률 · 회피 = 결과표를 옮기는 것 · 불운 보정.

## 10장. 고유 기술이 게임에 들어오다 (2026-10-23 ~ 10-24)

- **순서(사용자 결정):** 엑셀 v10 공통 효과를 전투에 먼저 → 같은 장치 묶음으로 종을 하나씩 → 몇 종씩 모아 밸런스를 본 뒤 친구 서버.
