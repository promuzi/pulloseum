# 제작 과정 릴스 · 저작권 · 게임 제목 · 상표 (2026-10-16)

사용자 "이 게임 제작 과정을 릴스로 올릴 건데 저작권이나 게임 제목, 상표 등 어떤 조치를 취하는 게 좋을지". 법률 자문이 아니라 조사 정리 — 상표 출원처럼 돈이 드는 일은 변리사 상담 1회를 권함.

## 1. 지금 바로(돈 안 드는 것)
1. **이름 확인:** 웹 검색으로 '풀로세움 · Pulloseum' 게임 · 상표 흔적 없음(2026-10-16). KIPRIS(특허정보넷) 전체 검색 = 특허 0건 — **상표 탭은 직접 한 번 확인**(kipris.or.kr → 상표 → '풀로세움' · '플로세움' · 'Pulloseum' 호칭 검색, 지정상품 제9류 · 제41류). 구글 플레이 · 앱스토어 · 스팀 · 인스타 계정 · 도메인도 같은 이름이 있는지.
2. **흔적 남기기:** 릴스 · 깃 기록 · 문서 날짜가 '먼저 만들었다'는 증거가 됨. 원본 그림 · 컨셉 · 코드는 지금처럼 저장소에 날짜와 함께(공개 저장소는 남이 베끼기도 쉬우니 그림 원본 공개 범위는 따로 판단).
3. **릴스 음악:** 남의 노래를 깔지 말 것(짧게 써도 안전 구간 없음, 사업자 계정은 메타 음원 모음만). **게임 소리(우리 코드가 만든 효과음 · 칩튠)를 그대로 쓰는 게 가장 안전.** AI 음악을 쓰면 유료 요금제에서 받은 파일만.
4. **AI 표시:** 사람처럼 보이는 실사 AI 영상 · 음성이면 메타의 'AI 정보' 표시 대상. 도트 그림 · 개발 화면은 대개 아님 — 다만 "그림은 AI로 컨셉을 뽑고 직접 다듬었다"처럼 과정에서 솔직하게 말하면 신뢰에 좋음.
5. **남의 것 보여 주지 않기:** 참고한 게임(포켓몬 · 페르소나 · Balatro 등)의 화면 · 캐릭터 · 로고를 영상에 넣지 말 것. 기법을 배운 것은 괜찮고, '~ 같은 게임' 소개 문구는 상표 혼동이 없게.
6. **글꼴 · 도구:** 프리텐다드(OFL) 등 지금 쓰는 글꼴은 영상 · 게임에 써도 됨. 코드로 만든 소리는 우리 것.

## 2. 상표(게임 제목) — 릴스로 이름이 알려지기 전에 출원 권장
- 우리나라는 **먼저 출원한 사람이 권리**(선출원주의). 영상이 퍼진 뒤 남이 먼저 출원하면 다툼이 됨 → **공개 전 또는 직후 출원**.
- 류(지정상품): **제9류**(내려받는 게임 프로그램 · 앱) + **제41류**(온라인 게임 서비스). 굿즈까지 생각하면 제28류(장난감 · 게임 용구) · 제25류(옷) 등은 나중에.
- 무엇을: 글자 상표 '풀로세움'과 'PULLOSEUM'을 각각(또는 함께). 로고가 정해지면 로고도.
- 비용(관납료, 출원 전 특허청 · 특허로에서 현재 금액 다시 확인): 전자출원 1류 약 6만 2천 원(2024 기준, 지정상품 10개 이하) → 2개 류 약 12만 원. 등록 결정 후 등록료가 류마다 더 듦(자료마다 3년분 · 10년분 표기가 달라 직접 확인). 변리사 대행이면 수수료 별도.
- 방법: '특허로'(patent.go.kr)에서 직접 전자출원 가능(공동인증서). 심사는 1년 안팎 — 그동안도 '출원 중'으로 먼저 출원한 사실이 남음.
- 이름이 겹치면: 부제 붙이기 · 다른 분야와 공존 합의 · 이름 바꾸기. 게임 낼 나라마다 따로(상표는 나라별).

## 3. 저작권
- 게임(코드 · 그림 · 소리 · 글)은 **만든 순간 저작권이 생김** — 등록하지 않아도 됨.
- **등록하면 좋은 점**(한국저작권위원회, 선택): 등록된 날 만든 것으로 추정(만든 뒤 1년 안에 등록해야), 침해 때 법정손해배상(저작물마다 1천만 원, 영리 · 고의면 5천만 원 이하) 청구 가능. 출시 직전 '프로그램' + 대표 캐릭터 '미술'로 등록을 검토.
- **AI가 섞인 부분:** AI만으로 만든 결과는 등록되지 않고 사람이 만든 · 고친 · 고르고 배열한 부분만 인정 → 등록 신청 때 AI 부분과 사람 부분을 나눠 적어야(거짓이면 처벌). 우리 식물 그림은 '코덱스 컨셉 → 우리가 도트로 변환 · 손질'이라, 변환 · 손질 과정 기록(저장소 · 문서)을 남겨 두는 게 좋음.
- OpenAI(코덱스) 결과물은 약관상 사용자에게 권리를 넘김(사용 권리) — 다만 위처럼 저작권 '보호'는 별개.
