루트 지침에서 옮긴 분야별 세부다. 해당 분야를 수정하기 전에 필요한 절을 읽는다. 최신 구현 경계는 [마스터 로드맵](master-roadmap.md)과 [최근 인계](superpowers/specs/2026-10-16-v2-mvp-design.md)가 우선한다. 아래 본문은 2026-10-18 축약 직전 원문을 보존했으므로 당시 수치·상태가 포함돼 있다. 상대 코드 경로는 저장소 루트 기준이다. 첫 절의 첫 출시 제외 항목은 과거 계획이며, 현재 3:3·카드는 이미 구현됐다. 검증 개수는 당시 결과다.
