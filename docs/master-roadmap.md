- **지금:** 19번 톡시캑터(2026-10-26) · 20번 드라코프루트(2026-10-28) 설계 확정 — 기술 여섯 · 진화 배치 · 캐릭터 네 항목 · 둘 다 종 고유 패시브 없음. 정리판 = [종 고유 기술 표](superpowers/specs/2026-10-18-v2-species-skills.md) · [캐릭터 문서](lore/plant-characters.md) 각 19 · 20번. 수치는 밸런스 때이며 게임 적용 전. 별도 말투 · 추가 대사 · 관계는 미지정.
- **톡시캑터:** 새싹 = 독 주머니 폭발 / 성장기 = 신경독 · 독안개 / 성체 = 만천화우 · 좋은 거 주입 · 독점사. 독안개 = 상대 쪽에만 3턴간 계속 독을 거는 환경 기술. 만천화우 = 광역 + 연타 + 독, 각 타 적중 시 그 타의 독 부여까지 반영해 독 5겹이면 출혈(이미 5겹이어도 · 마지막 타에 5겹이 되어도 발동, 빗나간 타에는 안 걸림).
- **드라코프루트(고유 패시브 없음 — 2026-10-28 확정):** 빙결열매를 얻으면 왼쪽 태양 하나가 얼고, 열매 하나당 방어력이 증가한다. 보유 중 시간제한 없이 유지되고 정화나 여러 기술로 제거할 수 없지만 **열매를 소모하면 해당 방어 증가분도 사라진다**. 빙결 효과 기술(공통 기술 포함 무엇이든 — 2026-10-27) 사용 시 연타·적중과 관계없이 열매 1스택, 열매 소모 기술은 생성 제외. 냉기 응축은 빙결 효과 없이 열매 1스택 + 태양 하나. **진화 배치(2026-10-27 확정): 새싹 = 냉기 응축 / 성장기 = 열매 먹기 · 알 깨기 / 성체 = 빙결 브레스 · 빙결 폭풍 · 열매 던지기.** 3:3 교체로 대기석에 가도 열매 · 방어 증가분은 그대로(2026-10-27 확정). 여섯 기술 방향은 [종 기술 표](superpowers/specs/2026-10-18-v2-species-skills.md) · [캐릭터 문서](lore/plant-characters.md) 20번. 게임 적용 전.
- **햇빛 리스크:** 열매는 햇빛 칸을 차지하고 기술 비용으로 쓸 수 없다. 비용 2인 빙결 기술 사용: 햇빛 3 → 열매 1 → 다음 턴 열매 1 + 일반 햇빛 1, 비용 2 이상 기술 사용 불가. 소모한 열매 1개당 사용 가능한 햇빛 1개로 돌아온다(사용자 확정). 많이 쌓이면 소모하도록 하는 리스크다.
- **생성 예외(사용자 확정):** 비용 지불 후 잠글 일반 햇빛이 없으면 잠기지 않고 빙결열매도 추가되지 않는다. 예: 햇빛 2에서 비용 2인 빙결 기술 사용 → 남은 햇빛 0 → 열매 추가 없음.
- **열매 먹기 정화 확정:** 열매 1개당 상태이상 1종의 모든 겹 제거. 독 5겹도 열매 1개로 모두 제거하며, 열매는 전부 소모한다. 열매보다 종류가 많으면 지울 종류는 무작위(같은 확률 · 중복 없음 — 2026-10-28 확정, 10-19 부분 정화 규칙과 같음). 회복은 먹은 열매 수에 비례(열매 1개당 정해진 만큼 — 2026-10-28 확정).
- **빙결 브레스 소모량 확정:** 가진 빙결열매 전부 소모 → 광역 공격 + 소모한 열매 수만큼 빙결 부여. 열매는 새로 쌓지 않는다.
- **열매 던지기 확정:** 열매 전부 소모 → 열매 1개당 무속성 1타, 각 적중마다 빙결 1겹. 빗나간 타는 빙결 부여 없음. 열매는 새로 쌓지 않는다.
- **열매 0개 제한 확정:** 열매 먹기 · 빙결 브레스 · 열매 던지기는 빙결열매가 없으면 사용 불가.
- **소모 기술 비용 확정:** 열매 먹기 · 빙결 브레스 · 열매 던지기 모두 햇빛 0. 열매 0개면 사용 불가 · 전부 소모 · 방어 증가분 소멸 · 햇빛 복귀 · 새 열매 생성 없음은 유지한다.
